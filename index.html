Quick Start
  1. Set a scene id + name.
  2. Place and shape the path.
  3. Shape the path, shells, and timing.
  4. Save to Library or Export JSON.
Assembly Editing
Assembly Editing
  • Click or drag the assembly center handle labeled A, B, C, and so on.
  • Right-click an assembly center handle to edit that assembly.
  • Right-click empty canvas space to add built-in assemblies or path points.
Transfers
Transfers
  • Map a member from one assembly to another.
  • Use `assembly.member -> assembly.member @ time`.
  • Example: `assembly_1.positrino_1 -> assembly_2.positrino_1 @ 6.0`
No transfers authored.
Reactions
Reactions
  • Group transfer lines into named timeline stages.
  • Use `label @ start-end: transfer-lines | action, action`.
  • Stages can target subsets like `detach(1), handoff(1,2), reassemble(2)`.
  • Example: `handoff @ 5.2-6.4: 1, 2 | detach(1), handoff(1,2), reassemble(2)`

Save / Library
