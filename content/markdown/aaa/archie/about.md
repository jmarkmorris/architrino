# About

## What This Is

Architrino enables exploration of the reductionist universe via interactive scene graph of structure, assembly, and concepts as nested spheres. It combines visual navigation with attached documentation and interactive tools.

## Core Navigation Model

- A sphere represents a node in a hierarchy.
- Selecting a sphere can open a child scene or content.
- `Back` returns up one step in your navigation path.
- `Home` returns to the root scene.
- `Archie` opens the meta/navigation space.

## Content Model

A node may resolve to:

- Markdown documentation
- Another scene (sub-graph)
- A dedicated app/tool view (for example, Composer)
- Media or mixed experiences

## Project Status

This environment is actively evolving. Structure, labels, and content depth may change as scenes and documents are refined.

## Orientation Tips

- Use scene search (`Cmd/Ctrl + K`) when you know a target name.
- Use markdown in single- or two-column mode depending on reading preference.
- Use `Back` for local navigation and `Home` for full reset.
