## Problem Map

Use [Solving Open Problems With $\mathbb{A}\mathbb{A}\mathbb{A}$](solving-open-problems.md) as the canonical reader-facing problem map.

The map separates:

1. what current physics gets right,
2. what remains mechanistically or ontologically unresolved,
3. which inherited repair attempts remain useful as comparison frameworks,
4. which $\mathbb{A}\mathbb{A}\mathbb{A}$ route is being proposed,
5. and which falsifier or closure target would count as resolution.

This keeps paradoxes from becoming slogans. A paradox is useful only when the secure record, inherited formal move, and unresolved substrate question are separated.
