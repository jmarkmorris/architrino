# Determinism Beneath the Quanta: A Tentative Mapping Between 't Hooft CAI and AAA

This document is a comparative draft. It highlights structural similarities and differences between Gerard 't Hooft's Cellular Automaton Interpretation (CAI) and Architrino Assembly Architecture (AAA), without claiming equivalence.

## 1. Shared Motivation

Both CAI and AAA are often read as attempts to place quantum statistics on top of deeper deterministic dynamics.

* **CAI:** Deterministic update rules on a discrete state space, with Hilbert-space machinery used as an effective description.
* **AAA:** Deterministic path-history dynamics in an absolute-time framework with discrete assemblies in continuous Euclidean space.

## 2. Concept Dictionary (Provisional)

| CAI concept | AAA analogue (working) |
| :--- | :--- |
| Ontological state | Full architrino configuration + history segment |
| Beables | Primitive point entities and kinematic variables |
| Templates/superpositions | Coarse-grained statistical descriptions of unresolved microstate detail |
| Cogwheel model | Periodic binary or tri-binary assembly cycles |

## 3. Key Divergence

CAI is lattice/discrete at the kinematic base; AAA keeps continuous substrate coordinates while using discrete assemblies and delayed interactions. Because of this, they differ in how they approach locality, Lorentz recovery, and Hamiltonian structure.

## 4. Quantization and Stability

't Hooft's cogwheel construction shows how deterministic periodic systems can admit quantum-like operator descriptions. AAA may admit a related interpretation if stable assembly cycles play the role of discrete clock states.

This is suggestive, not yet a proof of equivalence.

## 5. Bell/Superdeterminism Context

CAI discussions often include superdeterministic responses to Bell constraints. AAA can be interpreted in a similar direction, but this remains an interpretive stance until explicit Bell-CHSH reproductions are shown in simulation.

## 6. Information Loss vs. Coarse-Graining

CAI sometimes uses equivalence classes/information loss language. AAA tends to frame the same territory as coarse-graining of unresolved internal variables in complex assemblies. Whether these are mathematically equivalent in concrete models is an open technical question.

## 7. Working Conclusion

CAI and AAA appear to be conceptual neighbors in the deterministic-foundations landscape. The right next step is not rhetorical alignment but model comparison:

1. Define matched toy systems in both formalisms.
2. Compare invariant measures and emergent observables.
3. Check where predictions agree, diverge, or fail.
