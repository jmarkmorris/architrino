# Open Problems

## Purpose

Track unresolved cosmology questions while the Architrino theory is still being consolidated.

## Priority Set

- Dark-energy interpretation
- Dark-matter interpretation
- Inflation mechanism
- Hubble tension context
- $S_8$ tension context
- Lithium anomaly integration
- Matter asymmetry origin
- Early-universe trans-Planckian interpretation

## Working Principle

At this stage, each problem should be developed toward conceptual coherence first:

1. one clean mechanism statement,
2. one ontology-consistent vocabulary,
3. one integration path with neighboring cosmology topics.

## Theory Priorities

- Reduce duplication of competing internal explanations.
- Keep background-expansion, CMB, and growth stories mutually consistent.
- Separate stable commitments from tentative exploratory ideas.
