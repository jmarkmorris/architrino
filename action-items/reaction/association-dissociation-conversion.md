# Association / Dissociation Conversion Plan

This document is the first-pass conversion plan for moving $\mathbb{A}\mathbb{A}\mathbb{A}$-first reaction language from `decay`-style assembly-event wording to `associate` / `dissociate`.

Scope notes:

- The table covers usages that should change in $\mathbb{A}\mathbb{A}\mathbb{A}$-first prose.
- It does not target mathematical or continuum phrases such as geometric decay, orbital decay, decaying amplitudes, or decaying equations of state.
- It does not force changes where a Standard Model label is itself the object of comparison, though some mixed-level sentences should still be rewritten for cleaner translation.
- In meson chapters especially, many `decay` uses are structural-basin or channel-change descriptions with energy or flux tension as the trigger. Those should usually convert to `dissociate`, while the trigger language itself may stay as energy/tension language.
- Default replacement policy: when a sentence is using `decay` as generic channel narration rather than a fixed canonical label, replace it with `reaction` first, then sharpen to `associate` / `dissociate` / `reconfigure` where the mechanism is known.
