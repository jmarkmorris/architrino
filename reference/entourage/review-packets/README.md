## Packet Discipline

- Keep packets self-contained.
- Start the packet body with a `Closure goal:`.
- Ask first for overall insights, corrections, and advancements.
- Then ask specific questions.
- Include a requested comment count for the round.
- Avoid repo-specific filenames in the packet body unless the reviewer has repo access.
