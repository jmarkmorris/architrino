# Learning Model Design

This directory owns the canonical learning-model standards for the scene metaphor: how reader-facing scenes organize understanding and how textbook material is structured for that scene-driven experience.

These documents guide authors and developers, but their primary ownership is learning design rather than visual identity or implementation architecture.
