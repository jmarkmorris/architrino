# Children's Book Production Prompts

This folder holds book-specific image-generation briefs for the children's book production pipeline.

These prompts are preserved production inputs. They describe source illustrations for named books, covers, spreads, and backmatter activities and remain tracked alongside the manifest and QA records. Page layouts and derivative exports are optional local outputs; follow the [on-demand export procedure](../README.md). Prompts alone cannot reproduce the exact original artwork, so retain the source PNGs.

For reusable agent/operator workflow prompts, use the [CTO prompt library](../../../../research-office/cto/prompts/README.md).
