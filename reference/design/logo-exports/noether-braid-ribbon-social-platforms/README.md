# Noether Braid Ribbon Social Platform Exports

This package contains platform-named social branding exports generated from the current Noether Braid ribbon app icon master.

- Source PNG: `../noether-braid-ribbon-app-icon/noether-braid-ribbon-app-icon-1024.png`
- Manifest: `manifest.json`
- Upload assets are RGB PNG files.
- `circle-crop-preview` files are transparent preview aids for platforms that render avatars in circular masks; use the corresponding square avatar/icon file for upload unless the platform specifically asks for a circular PNG.

## Avatar And Icon Assets

- YouTube: `noether-braid-youtube-avatar-800x800.png`
- LinkedIn profile: `noether-braid-linkedin-profile-avatar-400x400.png`
- LinkedIn company logo: `noether-braid-linkedin-company-logo-300x300.png`
- Reddit community icon: `noether-braid-reddit-community-icon-512x512.png`, `noether-braid-reddit-community-icon-256x256.png`
- Discord server icon: `noether-braid-discord-server-icon-512x512.png`
- Cross-platform master: `noether-braid-all-platforms-avatar-master-1024x1024.png`
