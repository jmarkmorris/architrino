# Design

This directory is for durable design reference material.

Use it for subsystem boundaries, contracts, invariants, and design guidance intended for developers rather than the app runtime.

Design reference should describe the current canonical design. Keep abandoned alternatives and decision rationale in [../architectural-decisions](../architectural-decisions/README.md) or GitHub. Do not keep a mixed old/new implementation path unless the operator/developer explicitly requests a temporary transition.
