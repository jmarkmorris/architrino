# Design

This directory is for durable design reference material.

Use it for subsystem boundaries, contracts, invariants, and design guidance intended for developers rather than the app runtime.

Design reference should describe the current canonical design. Keep migration history, abandoned alternatives, and decision rationale in [../adr](../adr/README.md) or GitHub unless the earlier state is still an active compatibility constraint or removal condition.
