# Noether Braid Profile Banner Candidates

Status: rejected.

These candidates are generated banner backgrounds intended to sit behind the Noether Braid social profile logo. They do not include the logo, QR code, or brand text inside the banner itself.

Rejection note: this direction used chalkboard/equation language and did not follow the final banner constraint that candidates use only reds, purples, and blues while emphasizing paths and wakes.

- Contact sheet with profile-logo overlay: `noether-braid-profile-candidates-contact-sheet.jpg`

- Quiet Noether Sea: `quiet-noether-sea-2560x1440.png`
- Hybrid chalkboard plus Noether Sea: `hybrid-chalkboard-noether-sea-2560x1440.png`

The `*.png` files without the `2560x1440` suffix are the direct built-in image-generation outputs copied into this package before local resizing.

## Rejected Ranking Snapshot

1. Hybrid chalkboard plus Noether Sea: strongest balance of serious physics, visual energy, and avatar support.
2. Quiet Noether Sea: cleanest and safest behind the profile logo; less intellectually distinctive than the hybrid.
3. Chalkboard equation field: high audience pull for math/physics, but it competes with the circular profile logo and risks looking like a generic physics board.
