# Play-Surface Concept Images

Status: saved first-pass concept examples, not final CAD, safety review, or manufacturing definition.

These examples show the basic white tile form, sidewall visibility, smooth unpatterned rolling surface, and a separate profile strip. The profile strip shows the cosine-lobe hill or dip used to generate the tile surface: no flat top, no flat bottom, and no forced `45` degree midpoint tangent.

The product-view portion is still a visual reference, not proof-grade CAD. For final exemplar review, keep pairing each product-view render with a cross-section or profile plot that shows the sine-eased level change directly.
