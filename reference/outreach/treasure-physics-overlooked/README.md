# Treasure Physics Overlooked Review Companions

These companion packets support review of [The Treasure Physics Overlooked](../../../content/markdown/aaa/philosophy-history/treasure-physics-overlooked.md). They are review surfaces, not replacements for the essay or for technical proof papers.

| Packet | Use |
| --- | --- |
| [Executive And NSF Review Packet](executive-nsf-review-packet.md) | A short non-historical case for why the program is worth serious review and what would count as funded progress. |
| [Technical Proof-Burden Map](technical-proof-burden-map.md) | A structured map of the four main open technical burdens: Lorentz recovery, Born/Bell recovery, redshift/cosmology, and compact-object bridging. |
| [External Reviewer Packet](external-reviewer-packet.md) | A cover packet for reviewers without repo access: essay link, glossary, known open burdens, and requested review focus. |

The core distinction used across these packets is simple: a **written closure** is a bridge equation or ledger already stated with source variables, target variables, fallback regime, and failure condition; a **declared burden** is an acceptance condition the essay states honestly but does not yet discharge.
