# What Changed?

Book: 5

Age interval: `4-5`

Series frame: **The Wonder of Nature and the Universe**

Wonder question: What changed?

Discovery sentence: Change one thing, compare what happened, and learn from the difference.

Text status: text-only manuscript draft; no image prompts in this pass.

## Book Promise

This pre-K book teaches:

1. Predict before trying.
2. Change one thing.
3. Compare what happened.

Parent/teacher terms: `prediction`, `controlled change`, `comparison`, `model`.

## Read-Aloud Manuscript

### Cover

Read-aloud title:

> What Changed?

### Spread 1: The Question

Read-aloud text:

> Electra watched the red ball roll.
>
> "Why did the ball go there?"

Editor note:

Wonder begins with noticing.

### Spread 2: First Try

Read-aloud text:

> The red ball rolled from the star.
>
> It stopped in the dip.

Editor note:

A first try gives a result.

### Spread 3: Remember It

Read-aloud text:

> Poz drew the path.
>
> "This is what happened."

Editor note:

A record helps comparison.

### Spread 4: Predict

Read-aloud text:

> "If we try again,"
>
> Electra asked,
>
> "where will it go?"

Editor note:

A prediction is a careful guess.

### Spread 5: Same Start

Read-aloud text:

> Same start.
>
> Same push.
>
> Same path.

Editor note:

Keeping things the same can repeat a result.

### Spread 6: One Change

Read-aloud text:

> Poz changed one thing.
>
> Only one.

Editor note:

Changing one thing makes the test clearer.

### Spread 7: New Path

Read-aloud text:

> The ball rolled again.
>
> This time it turned left.

Editor note:

The one change changed the path.

### Spread 8: Compare

Read-aloud text:

> Old path.
>
> New path.
>
> What changed?

Editor note:

Comparison shows the difference.

### Spread 9: Try A Hill

Read-aloud text:

> They swapped in a hill.
>
> The ball slowed near the top.

Editor note:

Different places guide motion differently.

### Spread 10: Try A Flat

Read-aloud text:

> They tried a flat path.
>
> The ball rolled straight through.

Editor note:

Flat places can preserve a simpler path.

### Spread 11: Tell The Rule

Read-aloud text:

> Electra pointed.
>
> "The path changes when the ball meets something new."

Editor note:

A child can state a rule from evidence.

### Spread 12: Wonder Grows

Read-aloud text:

> "What should we change next?"
>
> Poz asked.

Editor note:

One answer can open the next question.

## Parent Note

This book turns play into early experimental discipline. It should still feel like play, but the child now learns the pattern: predict, change one thing, observe, compare.
