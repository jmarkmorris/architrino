# Again Makes A Pattern

Book: 4

Age interval: `3-4`

Series frame: **The Wonder of Nature and the Universe**

Wonder question: What happens if we do it again?

Discovery sentence: Repeated paths can make a pattern.

Text status: text-only manuscript draft; no image prompts in this pass.

## Book Promise

This preschool book teaches:

1. Repetition can make a pattern.
2. Near and far change the pattern.
3. Overlap can be noticed.

Parent/teacher terms: `repeat`, `pattern`, `near`, `far`, `overlap`.

## Read-Aloud Manuscript

### Cover

Read-aloud title:

> Again Makes A Pattern

### Spread 1: The Wonder

Read-aloud text:

> Nia looked at yesterday's trail.
>
> "What if we do it again?"

Discovery:

A repeated action can become a question.

### Spread 2: First Roll

Read-aloud text:

> The red ball rolled across the tiles.
>
> One path appeared.

Discovery:

One run can be seen as one path.

### Spread 3: Second Roll

Read-aloud text:

> The blue ball rolled next.
>
> Its path came close.

Discovery:

Two paths can be near each other.

### Spread 4: Almost Same

Read-aloud text:

> "It almost followed the first one,"
>
> Nia said.

Discovery:

Similar paths can be compared.

### Spread 5: Farther Start

Read-aloud text:

> Papa moved the ball farther over.
>
> The path changed.

Discovery:

Starting place matters.

### Spread 6: Nearer Start

Read-aloud text:

> Mama moved the ball near the old mark.
>
> The paths met.

Discovery:

Near starts can make overlapping paths.

### Spread 7: Over And Under

Read-aloud text:

> One line crossed another.
>
> Nia traced the crossing with one finger.

Discovery:

Patterns can include crossings.

### Spread 8: Many Tries

Read-aloud text:

> Roll.
>
> Roll.
>
> Roll.
>
> The page grew busy.

Discovery:

Many runs can reveal structure.

### Spread 9: The Quiet Shape

Read-aloud text:

> The marks were not random.
>
> They made a quiet shape.

Discovery:

A pattern can appear from repetition.

### Spread 10: Predict

Read-aloud text:

> "I think the next one goes here,"
>
> Nia said.

Discovery:

Patterns support predictions.

### Spread 11: Test

Read-aloud text:

> They rolled once more.
>
> The new path joined the shape.

Discovery:

A prediction can be tested.

### Spread 12: Again

Read-aloud text:

> Again made a pattern.
>
> The pattern helped them see.

Discovery:

Repeated motion can reveal nature's order.

## Parent Note

This book prepares later superposition and assembly ideas without naming them. The child only needs the experience that many paths, taken together, can reveal a pattern.
