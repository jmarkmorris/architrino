# Treasure Physics Overlooked Review Set

This folder preserves an earlier review set. Its claims and acceptance labels are historical proposals, not current theorem or queue status. Use the [current Research Revolution materials](../../research-revolution/README.md) for present review routing and the live corpus for mathematical authority. A stated bridge equation alone does not establish closure; its derivation, assumptions, evidence, and recovery scope require independent assessment.

The Treasure Physics Overlooked review set uses separate review materials for executive readers, technical proof readers, and outside reviewers. The shared task is to preserve the force of the historical case while keeping every acceptance condition tied to a finite technical burden.

| Document | Use |
| --- | --- |
| [Science And Technology Leaders Review](science-technology-leaders-review.md) | A short non-historical case for why the program is worth serious review and what would count as funded progress. |
| [Technical Proof-Burden Map](technical-proof-burden-map.md) | A structured map of the four main open technical burdens: Lorentz recovery, Born/Bell recovery, redshift/cosmology, and compact-object bridging. |
| [External Reviewer Brief](external-reviewer-brief.md) | A reviewer brief with glossary, known open burdens, and requested review focus. |

The core distinction is simple: a **written closure** is a bridge equation or ledger already stated with source variables, target variables, fallback regime, and failure condition; a **declared burden** is an acceptance condition the work states honestly but does not yet discharge.
