## Scope

This workstream owns the speculative `braid-ideal` lane. The working intuition is that a Noether braid may admit a very simple same-level branch: all six architrinos operate at basically the same branch energy level, with comparable relative speed magnitude and comparable distance from the dynamic center. If such a branch exists, it would maintain that configuration unless destructively perturbed, and it could exchange action/energy through $h$-scale transactions.

The word `ideal` is deliberately speculative. It marks the hope that the branch may be simple enough that, if it works, the simpler structure will look obvious in retrospect. It is not a canon claim, not a theorem row, and not a replacement for nested shell braid closure unless a retained branch chart, root ledger, wake ledger, action ledger, and stability certificate support it.

This lane should stay general. It should not assume circular orbits, fixed binary planes, or a static sphere. The same-level condition may be realized by closed curves, rosette-like trajectories, quasi-periodic paths, chaotic-but-bounded basin measures, or a translating ellipsoid support. The central question is whether the six architrinos occupy one common dynamical level while retaining enough phase organization and shielding to be stable.
