The threshold is an analysis choice: any complete valid Taylor contract is already an enclosure, and soundness does not depend on it outperforming an alternative. The threshold changes neither a physical parameter nor the nonlinear trial bounds.

The selected dictionary preserves the candidate delay interval, candidate source interval, vector box, reference displacement, complete-speed bound and member identities together, adding only the method tag. Otherwise the original screened polynomial/midpoint dispatcher receives the same arguments. No fields are mixed between geometry constructions. An unavailable Taylor result signaled by `ValueError`, `AssertionError` or `ArithmeticError` falls back. Unexpected interface errors propagate. A required fallback failure also propagates; it does not become a successful enclosure.
