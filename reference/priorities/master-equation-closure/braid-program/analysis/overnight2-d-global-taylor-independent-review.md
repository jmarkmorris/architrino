## Derived acceleration and remainder contract

The [domain construction](overnight2-d-dense-region.py), previously independently audited in the [prefront review](overnight2-d-prefront-admission-independent-review.md), defines the reference by exact initial positions and accumulated encoded increments, shared velocity nodes, cubic Hermite interpolation and the correction $q^2(1-q)^2R(q)$. A cubic Hermite acceleration is affine in normalized time, so its Euclidean norm is at most the larger endpoint norm. If $R_\ell$ bound the correction polynomial and its first two normalized derivatives in Euclidean norm, the complete correction acceleration is bounded by

$$
A_c=\frac{2R_0+R_1+R_2/16}{h^2}.
$$

The instrument constructs $R_\ell$ using coordinate absolute sums, then adds $A_c$ to the Hermite endpoint-norm maximum and takes the maximum over all positive cells. This yields each recorded complete Euclidean bound $M_j$. It need not exceed a separately computed component-L1 bound of the full acceleration. Both ordinary acceleration traces at a knot are covered.

On any positive candidate source interval in the completed domain, $Q'$ is absolutely continuous: the finite polynomial pieces have shared position and velocity nodes. Integrating the acceleration twice around a center $u_0$ gives

$$
Q(s)=Q(u_0)+Q'(u_0)(s-u_0)+e(s),\qquad
|e(s)|\le M_j|s-u_0|^2/2.
$$

The point intervals enclose the first two terms. The polynomial range of $s-u_0$, including its uniform remainder, supplies the radius. Adding the same scalar remainder to each coordinate enclosure is conservative because each coordinate error is bounded by the Euclidean norm error. This does not differentiate an arbitrary uniform remainder.

The positive-domain guard rejects source intervals at or across zero, beyond the complete endpoint, or with a different loaded reference endpoint. Negative candidates keep the old local construction; a candidate crossing birth falls back through the existing screened selector. The enlarged true-root source interval may still require the inherited event and complete-piece machinery. The downstream matrix evaluation remains unchanged and still encloses vector source velocity and acceleration throughout that enlarged interval. The scalar $M_j$ is not substituted for those vector boxes.

## Required consumed-domain identity correction

The new main snapshots a parsed domain object. The first pending bind checks equality to that object and verifies its dependency closure, then activates its bounds. However, neither this activation nor the wrapper's final cleanup binds the bytes of that consumed domain to the hash the frozen core captures later.

The independent synthetic control follows that exact ordering without invoking a scientific target: a private domain object containing eight bounds equal to $5$ is snapshotted, loaded and bound; activation succeeds. The private domain file is then replaced by an object containing bounds equal to $6$. At the later identity-capture point, the file hash matches the replacement and remains stable, while the active bounds are still $5$. The wrapper completes without rejection. Thus its claimed consumed-domain/object guarantee is insufficient to ensure that the receipt names the object actually used. The counterexample does not dispute the Taylor theorem under frozen inputs; it exposes a provenance gap if the file changes between consumption and identity capture.

Required repair: bind the actual consumed snapshot bytes or their identity through activation and the final/header provenance, and reject incompatible file replacement before any such evidence can be treated as an accepted application. A parsed equality check at the first bind alone cannot discharge that obligation. Earlier frozen sources and oracles should remain unchanged. The parent was notified before any target use.
