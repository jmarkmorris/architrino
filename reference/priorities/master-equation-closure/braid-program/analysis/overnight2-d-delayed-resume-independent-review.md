## Complete earlier history and first-new-cell semantics

Let the accepted prefix contain $n$ reception cells. The helper requires an integer count with $0<n\le N$, exactly $n$ records, consecutive cell indices and exact encoded endpoint times. Every record must contain all eight members in order. Each member's incoming value must equal its preceding saved envelope; its residual budget must equal the corresponding current complete residual inventory; and its seven ordered partner labels must be complete.

Each output error and trial must be finite and satisfy

$$
0\le E_i(T_k)\le E_i(T_{k+1})<U_i<\text{current velocity allowance}.
$$

The final stored velocity allowance must equal the final member maximum. These checks reconstruct

$$
\texttt{saved}=[E(T_0),E(T_1),\ldots,E(T_n)],
$$

not just $E(T_n)$. The entire array is necessary because a later causal source can fall in any earlier cell. Its nondecreasing endpoint values retain the previously certified within-cell bounds. Keeping only the final value would discard the sharper source-time lookup used by the unchanged method-of-steps calculation.

`resume_history` returns fresh envelope lists and a new outer list containing the unchanged prior record blocks. The main loop uses `range(len(records), args.cells)`, which starts at $n$, the first uncomputed reception cell. It does not start at $n-1$ or at `len(saved)=n+1`. All subsequent cells append their new envelope and record together. An equal-length reuse with $n=N$ computes no new cell and retains the final old allowance; this is consistent but supplies no extension.

The partial output begins with the original initial envelope and the count of resumed cells, then writes every prior record before any new record. The completed output contains the same prior blocks followed by the new blocks. Neither existing prior JSON nor its record values are modified. Dependency identities are checked again before the completed output is written. An interrupted new run remains partial evidence and does not turn newly appended rows into an accepted extension.
