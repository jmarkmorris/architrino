# Retaining complete residual cells from a closed bounded run

## Purpose and status

The long residual application emits each fully computed member-cell record only after its interval calculation has completed. A wall, memory or lifecycle limit can end a run before the requested final receipt is written. Its partial file then contains potentially useful completed calculations as well as a possible incomplete cell or trailing fragment. Losing the final aggregate file is not a mathematical refutation of every already completed row, but a partial file alone is not an accepted residual certificate.

The prepared [prefix extractor](overnight2-d-residual-prefix.py) copies only a contiguous complete cell prefix into a new receipt, leaving the original partial evidence unchanged. It performs no evolution, root solve, residual recomputation or modification of an earlier artifact. Its output requires independent mathematical and provenance adjudication before any trajectory consumer may use it. The [completed independent review](overnight2-d-residual-prefix-independent-review.md) accepts the repaired component for conditional evidence selection under this declared contract. No scientific partial target has been extracted; actual producer association and full mathematical row acceptance remain separate requirements.

## Preconditions and exact selection

The extractor requires an observed owned adaptive-residual run in the same checkout, with an exact matching output tag, explicit first-cell/count selection, all eight receivers in order, a terminal status and a closed process group. Only canonical separate option/value spellings are accepted; abbreviated options, equals spellings, duplicate options and unknown option names are rejected even when the producer's argument parser would accept them. Parsed or defaulted reference and domain arguments must match the partial header and its bound inputs. Both graceful completion and failed, stopped or timed-out runs are admissible lifecycle observations. The tool does not prove that this run created the partial: an earlier file followed by a failed same-name launch is a counterexample to that inference. Its output explicitly leaves creator association unestablished until independently checked launch and progress evidence supplies it. The declared run must be closed and the inspected file must stay unchanged during extraction; these checks alone do not authenticate its writer or exclude a future write.

The header must be complete, identify the increment-defined time-67 reference and carry unique dependency paths. Every retained source dependency must match its recorded SHA-256 identity. The extractor reads all newline-terminated records, rejects duplicate JSON keys and nonfinite numbers, and requires exact consecutive cell/receiver order beginning at the declared first cell. A malformed complete line or an unexpected extra record fails closed. A trailing line without a newline is treated as an incomplete fragment and its byte count is reported; it is never parsed as scientific evidence.

Only groups containing all eight ordered receiver records count as complete cells. The default selection is every complete cell available; an explicit smaller count must also select a nonempty prefix. Whole records after the selected prefix and any unfinished last cell remain in the preserved source file and are counted as unselected rows. Every selected cell index must lie in the mesh, and its interval must contain exactly two finite increasing values equal to the encoded cell endpoints. The selected row objects and their interval arithmetic are copied without alteration. Their mathematical correctness still belongs to the frozen producer's reviewed construction and the separate full-row audit, including partitions, all seven channels, source traces, interval integrals and any birth-bracket coverage.

The new receipt retains the original dependency inventory and adds the extractor source and exact original partial file as dependencies. It preserves the complete front inventory, comparison tag and selected cell/receiver inventory. Closing checks repeat every dependency identity and verify that both raw source bytes and the terminal lease stayed unchanged during extraction. New output is created exclusively; an existing output is never overwritten. The original raw file is the retained comparison for exact selected-row correspondence.

The observed closed run's elapsed time and terminal state are recorded with an explicit unverified-creator-association qualification. They cannot yet be called the partial producer's cost. Per-prefix wall time and peak RSS are explicitly null because they were not independently measured for that selection. Even after the association is separately established, the total run cost must not be relabeled as the cost of only its selected prefix. The scientific dependency chain binds the partial file and declared producer inputs; the operational lease is checked for stable closure but is not copied into scientific output or exposed with its control credentials.

## Known controls and acceptance boundary

Before any scientific target, shared-venv controls passed a synthetic stream beginning at cell 3 with nineteen complete rows and an eight-byte truncated tail. Exactly two complete eight-member cells are selected by default; selecting one returns exactly its first eight rows. The other three complete rows and the fragment are reported without promotion. Failure controls reject a duplicated receiver, a nonfinite number, an incomplete header, a Boolean cell index and a live or nonclosed lease. A separately inspected supervisor branch establishes the `timed_out` terminal spelling, which the controls also cover. Additional controls cover duplicate JSON keys, reference defaults and explicit overrides, and invalid or out-of-mesh endpoint intervals. These supplied controls do not replace independent review.

This extraction only makes completed evidence reviewable; it does not promote it. The reviewer must independently verify exact selected-row correspondence, actual producer association from launch/progress evidence, source identity and selection, complete mathematical coverage, the unchanged producer/input bindings and every residual bound needed by the proposed trajectory application. A matching output name or terminal lease alone cannot establish that association. The current admission runner separately rejects missing or duplicate cell/member coverage and rechecks partition integrals. Neither that consumer nor a successful extraction replaces independent acceptance.

An altered row, a missed channel or segment, a missing birth trace, inward arithmetic, a mismatched reference, a still-growing source, or promotion of an incomplete cell defeats use of the new receipt. A failure that concerns only an unselected later row does not by itself invalidate an earlier complete prefix; its independence must be established from the producer's sequential per-row contract and the separate review. No whole-run completion, later actual trajectory, time-67 admission or tail result follows from extraction.
