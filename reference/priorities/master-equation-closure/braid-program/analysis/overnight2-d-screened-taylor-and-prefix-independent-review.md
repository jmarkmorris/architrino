## Selection proof and runtime composition

For a valid reception cell $[a,b]$ and complete speed bound $0\le L<1$, the inherited screen uses a conservative lower bound on $q=L(b-a)/(1-L)$. It selects the complete valid Taylor contract only when that contract's root-shift upper is at most the threshold. The nonnegative threshold and its lower rounding were independently reviewed in the earlier [screened geometry review](overnight2-d-screened-and-prefix-independent-review.md).

Soundness needs a valid selected enclosure, not a minimal one. Returning a Taylor candidate's own delay, source range, vector, speed and root displacement together preserves that enclosure. The code does so and changes only the method label. If no usable Taylor result is returned, or its displacement is too broad for the selection heuristic, the same input goes to the frozen screened polynomial/midpoint dispatcher. It does not return to the earlier narrow Taylor dispatcher, and it does not mix fields between constructions.

The independent known case uses $L=1/4$ and width $3/2$, giving exact broad threshold $1/2$. A Taylor displacement upper of $1/8$ passes this screen while failing the prior width/100 threshold $3/200$; the actual dispatcher calls only Taylor in that case. A displacement upper of $3/4$ triggers the fallback. Controls verify the exact object identities of all selected contract fields and nonmutation of the input dictionary. The three documented unavailable-enclosure exceptions (`ValueError`, `AssertionError`, `ArithmeticError`) trigger fallback. Unexpected interface errors and failures of the required fallback propagate. All controls passed.

The broader threshold is a numerical analysis choice, not a new physical tolerance. It need not be broader than width/100 for every possible $L$; the meaningful implementation fact is that it uses the reviewed speed-width formula. It gives no ordering of complete matrix boxes or runtime guarantee. Source-before-cell, complete source and trace coverage, positive denominators, residual and birth allowances, saved history and simultaneous strict-trial checks remain unchanged.
