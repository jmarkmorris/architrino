# Affine receiver-sign correction to the blind account reference

This correction is frozen before subject disclosure. The [blind account reference](authorized-cases-ten-hour-reference-d-anisotropic-account.md) has one transcription error in its sentence naming the two individual affine rows: the second prefactor must also be negative. With the vector kernel $F(N,v)$ defined there, the two actual affine acceleration rows are

$$
 A_+=-\frac K{d^2}F(N,W-U/2),\qquad
 A_-=-\frac K{d^2}F(-N,W+U/2).
$$

The elementary static control $F(N,0)=N$ and $F(-N,0)=-N$ verifies opposite accelerations. The plus prefactor printed for the second row in the blind reference would instead give equal static accelerations and is false. The exact account derivative and the separately expanded center/relative formulas in that reference already use the corrected convention and remain unchanged. This is an author transcription correction, not a defect attributed to any subject; no subject has yet been read. The original frozen reference is preserved.
