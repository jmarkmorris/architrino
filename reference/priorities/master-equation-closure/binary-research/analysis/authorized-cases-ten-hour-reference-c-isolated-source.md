# Blind reference for a later nonordinary root from an isolated unit-speed source point

**Derived grade, before access to the associated subject.** Consider the same mirror pair $X_\pm(t)=\pm x(t)$ with complete speed at most one, positive release separation $|x_0|>0$, and one isolated unit-speed point at $t_0$. Write $x_0=x(t_0)$ and $u_0=x'(t_0)$ with $|u_0|=1$. Speeds are strictly below one elsewhere on the intervals under discussion. No actual spiral endpoint or continuation event is selected by these hypotheses.

If that source point becomes a nonordinary partner root at a later reception t, put $\tau=t-t_0>0$. The root equations and transmitter denominator are

$$
|x(t)+x_0|=\tau,\qquad
n=\frac{x(t)+x_0}{\tau},\qquad
D=1+n\cdot u_0.
$$

Since both n and $u_0$ are unit, $D=0$ forces $n=-u_0$. Therefore

$$
x(t)+x_0=-\tau u_0,
\qquad x(t)-x_0=-2x_0-\tau u_0.
$$

The integrated complete-speed inequality is strict over every positive interval because the unit-speed touch is isolated. Thus

$$
|2x_0+\tau u_0|<\tau
\quad\Longrightarrow\quad
|x_0|^2+\tau x_0\cdot u_0<0.
$$

A necessary geometric condition is consequently $x_0\cdot u_0<0$ and, in that case, $\tau>|x_0|^2/(-x_0\cdot u_0)$. Outward or tangential release, $x_0\cdot u_0\ge0$, excludes any later nonordinary partner root from that isolated source point. All strictly subfield source points have D positive automatically. Hence when this is the only unit-speed source point in the complete history, the outward/tangential condition excludes every later nonordinary partner root while the stated speed premise holds.

The necessary inward condition is not sufficient for an event on the actual coupled equation; it only removes this chord obstruction. Strict integrated chords also exclude every positive-delay self root throughout this class. If unit-speed motion occupies a whole interval, the strict inequality needs separate justification; equality cases are outside the isolated-touch premise. Falsifiers are failure of the mirror root sign, a missing unit-speed source point, or a non-strict chord attributed to an isolated touch. This analytical reference introduces no new physical history or computation.
