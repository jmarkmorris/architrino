## 1. Sub-range inclusion rule: statement, proof, admissibility, hand control

**What a certified record asserts (derived from the frozen continuation code, checked in my like-reception adjudication 3).** A certified step record carries a time hull $[a,b]$ with true start $t_s\in T_s=[a,\,b-\Delta]$ and true end $t_s+\Delta$; a start state $q(t_s)\in Q_0$, $\dot q(t_s)\in V_0$ (the exact end strings of the preceding certified step, or the restart strings); a start acceleration enclosure $\ddot q(t_s)\in a_0$; a rate enclosure $a_p$ of $d\ddot q/dt$ valid at every time of the step; and whole-step boxes $S\ni q$, $V_S\ni\dot q$, with $\ddot q\in a_0+a_p[0,\Delta]$ on the step.

**Rule (derived).** For a true offset $\sigma=s-t_s\in[0,\Delta]$, $\ddot q(s)\in a_0+a_p\sigma$, $\dot q(s)\in V_0+a_0\sigma+a_p\sigma^2/2$, $q(s)\in Q_0+V_0\sigma+a_0\sigma^2/2+a_p\sigma^3/6$. Proof: on a slab record (every record starts at or after $T^*$) the tangent acceleration is continuously differentiable, because the receiver's rate $d\ddot q/dt$ is a continuous function of $q,\dot q$ and of the delayed $q',\dot q',\ddot q'$ at strictly increasing source times, and the only jump of a delayed $\ddot q'$ is at source time $0$ (release), which no slab class reads again after its $T^*$ crossing is passed inside a step whose rate box encloses both one-sided values. Hence $\ddot q(t_s+\sigma)-\ddot q(t_s)=\int_0^\sigma \dddot q\in a_p\sigma$ (mean-value form of the integral of a function with values in the interval $a_p$), and two further integrations with the interval-valued integrand bounded termwise for $\sigma\ge 0$ give the other two lines. For a set of delayed arguments $\mathcal S$ (an interval) the offset set to be used is $\Sigma=(\mathcal S-T_s)\cap[0,\Delta]$: every true pair $(s,t_s)$ with $s$ inside the true step has $\sigma\in\Sigma$, and interval evaluation of the three polynomials over $\Sigma$ (each occurrence of $\sigma$ independent) is a superset of the union over $\sigma\in\Sigma$. If $\Sigma=\emptyset$ the record is not met. The lookup result is the hull over every record met. Any looser superset (for example a remainder written as $a_p[0,\sigma^k/k!]$ or $a_p[0,\Delta]$ factors) is also valid; a tighter set needs its own proof.

**Monotone endpoint refinement (derived).** The pointwise bounds $L(\sigma)=\underline{Q_0}+\underline{V_0}\sigma+\underline{a_0}\sigma^2/2+\underline{a_p}\sigma^3/6$ and the matching upper function $U(\sigma)$ satisfy $L'(\sigma)=$ the lower bound of the $\dot q$ line. Where that lower bound is positive on $\Sigma$, $q\in[L(\underline\Sigma),U(\overline\Sigma)]$; the same argument applies to $\dot q$ where the lower bound of the $\ddot q$ line is positive, and to $\ddot q$ where $a_p$ has a definite sign. Without the stated sign check the endpoint form is refused.

**Intersection (derived).** The whole-step box and the sub-range box are both enclosures of the same true values, so their intersection is an enclosure; an empty intersection is a contradiction and the row is refused, not repaired.

**Admissibility and refusal conditions (derived requirements).** (a) Only records with `certified: true` in the 204-record chain of section 2; an uncertified record (the 11th entry of wave-16 run 2 in particular) is refused. (b) Exact-string continuity of time, $q$ and $\dot q$ at every record boundary met; a gap or mismatch is refused. (c) Coverage: $\underline{\mathcal S}\ge$ the lower endpoint of the first record's start and $\overline{\mathcal S}\le$ the LOWER endpoint of the last certified end time (the true end may be that early); beyond-coverage is refused; in particular a delayed argument may never fall in the step being computed (true for all classes: delay $\ge r_{\min}>0.87\gg\Delta$). (d) The time origin is the uncertain $t_s\in T_s$; evaluating at $s-a$ without subtracting the width of $T_s$ is refused (it misses true values, shown below). (e) The start state used for record $k$ is the stored end-string interval of record $k-1$, parsed outward (padding $10^{-23}$ for 25-digit strings). (f) Below $T^*$ the window representation is not a slab record and this rule does not apply; no class reads below $T^*$ after the restart (antipode source time at the restart $\ge 1.464820058609396215298085>T^*$, measured in the frozen step 154), so any window read by the new lookup is a defect.
