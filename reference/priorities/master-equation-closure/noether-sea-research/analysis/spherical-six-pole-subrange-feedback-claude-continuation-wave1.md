## 2. Derivations

### 2.1 The sub-range inclusion rule (derived)

Let a certified step record have true start time $t_s$, start state $(q(t_s),\dot q(t_s))\in Q_0\times V_0$ (the certified enclosure of the preceding step's end, i.e. the strings the step was started from; for the first record the window state at $T^*$), start acceleration $\ddot q(t_s)\in a_0$, and an interval $a'$ that contains the acceleration rate $\dddot q$ almost everywhere on $[t_s,t_s+\Delta]$. For a step on which the rate is continuous this is what the frozen step certifies: it evaluates the rate on candidate sets $S\times V_S$ and on the delayed-state hulls of the whole step, and its closure test proves the motion stays in those sets. Then for $\sigma\in[0,\Delta]$: $\ddot q(t_s+\sigma)-\ddot q(t_s)=\int_0^\sigma\dddot q\in a'\,[0,\sigma]$; integrating once and twice, $\dot q(t_s+\sigma)\in V_0+a_0\sigma+a'[0,\sigma^2/2]$ and $q(t_s+\sigma)\in Q_0+V_0\sigma+a_0\sigma^2/2+a'[0,\sigma^3/6]$ (the products with $[0,\cdot]$ contain the exact convex-weighted remainders and equal the frozen step's own end formula at $\sigma=\Delta$). These enclosures are indexed by the step-relative time $\sigma$ and hold for whatever the true $t_s$ is.

Rate jumps, condition (A). The receiver's rate $\dddot q$ depends on the delayed source acceleration, which jumps from $0$ to $gF(0)$ at the source's release ($s=0$). Hence the receiver's rate jumps exactly when a class first reads source time $0$: at $T^*$ for the unlike class (the start of wave-16 step 1), inside wave-17 step 1 for the like class and inside antipodal b3 step 13 for the antipode. On such a record the polynomial form is valid only if the stored $a'$ covers both one-sided rates. The frozen steps did evaluate their rate on a two-regime hull there (the frozen history function returns the acceleration hull of $0$ and $gF$ whenever the delayed range reaches $s<0$; the stored delayed hulls of those classes start at the rest state; b3 step 13 carries an explicit two-regime flag), and control (R) verifies these stored facts; but the coordinator does not accept that inference as proof, so the instrument takes the conservative route: on these three records the lookup returns the record's separately certified whole-step box $(S,V_S,a_0+a'[0,\Delta])$ for every class, never the polynomial form. Later seam readings (of $T^*$ or of record joins) involve jumps of the source's rate, not of its acceleration, and therefore jumps of the receiver's fourth derivative only; they do not affect the rule.

Uncertain origin. The steps are exactly $\Delta$ long in true time and start at $t_s^{(k)}=T^*_{\rm true}+(k-1)\Delta$; only $T^*_{\rm true}$ is uncertain. A record's retained `t_int` is the full slab coverage $[{\rm lo}(T_0),\ {\rm up}(T_0)+\Delta]$, so its start time lies in $T_0=[t_{\rm int,lo},\ t_{\rm int,hi}-\Delta]$ (width $1.15559\times10^{-7}$, padded by $10^{-23}$). For an absolute delayed time $s$ in a range $s_{\rm int}$ the relative time with respect to record $k$ is $\sigma=s-t_s^{(k)}\in s_{\rm int}-T_0^{(k)}$, and the record applies only when $\sigma\in[0,\Delta]$ (no enclosure is certified beyond the slab): $\Sigma_k=(s_{\rm int}-T_0^{(k)})\cap[0,\Delta]$; if $\Sigma_k$ is empty the record cannot hold $s$. For every true $s$ between $T^*_{\rm true}$ and the true end of the last record there is a step $k$ with $\sigma\in[0,\Delta]$, and then $\sigma\in\Sigma_k$; therefore the true state lies in the hull, over all records with nonempty $\Sigma_k$, of the record boxes evaluated on $\Sigma_k$ (polynomial form on $\Sigma_k=[\sigma_a,\sigma_b]$: $Q_0+V_0\Sigma_k+a_0\Sigma_k^2/2+a'[0,\sigma_b^3/6]$ and likewise for $\dot q$, $\ddot q$; whole-step box for the three rate-jump records). For an ordinary record the whole-step box is also valid for every $\sigma\in[0,\Delta]$, so the per-record intersection of the two is valid (an empty intersection is treated as an error) and the result is never wider than the old hull. For a range reaching below ${\rm up}(T^*)$ the window enclosure (exact for $s\le T^*_{\rm true}$) is hulled in for the part $[s_{\rm lo},{\rm up}(T^*)]$ and the records for $[{\rm lo}(T^*),s_{\rm hi}]$.

Guaranteed coverage, condition (B). The true end of the last record is $t_s^{(K)}+\Delta\in[t_{\rm int,lo}^{(K)}+\Delta,\ t_{\rm int,hi}^{(K)}]$. A source time above the lower endpoint of that interval is covered only for some time origins, so the lookup refuses any range whose upper end exceeds $t_{\rm int,lo}^{(K)}+\Delta$ (minus the padding), for the frozen chain and after every self-append. (The earlier instruments compared with the upper endpoint; no earlier target came within $0.4$ of the end, so no earlier result depended on the difference.) Uncertified records, gaps, misaligned or discontinuous records are refused by the same checked chain as before.

What the rule does not do: it does not shrink any certified end state or the restart enclosure; it reads the same certified records more sharply.
