## 1. The sub-range inclusion rule (derived; my own proof)

**Setting.** A certified record $k$ (a "slab") of any retained chain is the statement: for the true solution and the true slab start time $\tau_k$, known only as $\tau_k\in T_k=[\underline t_k,\overline t_k]$ (the same unknown offset for every slab of a chain, $\tau_{k+1}=\tau_k+\Delta$, $\Delta=0.01$), (i) the start state satisfies $q(\tau_k)\in Q_0$, $\dot q(\tau_k)\in V_0$ (the record's retained start strings, equal by the chain-continuity control to the preceding record's end strings); (ii) the start acceleration satisfies $\ddot q(\tau_k)\in A_0$ (the record's `a0`); (iii) for every $\sigma\in[0,\Delta]$ the state lies in the whole-step candidate sets, $q(\tau_k+\sigma)\in S$, $\dot q(\tau_k+\sigma)\in V_S$, and the acceleration rate satisfies $\dddot q(\tau_k+\sigma)\in A_P$ (the record's `ap`, its enclosure of $d\ddot q/dt$ over the candidate sets, which is what its own affine step consumed). The recorded `t_int` is the coverage hull $[\underline t_k,\overline t_k+\Delta]$, not a start point.

**Rule.** For fixed $\sigma\in[0,\Delta]$, integrating (iii) from the start with nonnegative weights: $\ddot q(\tau_k+\sigma)=\ddot q(\tau_k)+\int_0^\sigma\dddot q\in A_0+\sigma A_P$; $\dot q(\tau_k+\sigma)=\dot q(\tau_k)+\ddot q(\tau_k)\sigma+\int_0^\sigma(\sigma-u)\dddot q\,du\in V_0+A_0\sigma+A_P\,\sigma^2/2$; $q(\tau_k+\sigma)\in Q_0+V_0\sigma+A_0\,\sigma^2/2+A_P\,\sigma^3/6$. The remainder is one-sided in the sense that it is an integral of the rate bound from the start only, never an extrapolation backward or beyond $\Delta$; each weighted integral of a function with values in the interval $A_P$ against a nonnegative weight of total mass $w$ lies in $w\,A_P$ (mean value), which is the whole proof. **Sub-range.** For a requested set of true source times $s\in[s_{\rm lo},s_{\rm hi}]$ the offsets into slab $k$ are $\sigma=s-\tau_k\in\Sigma_k:=([s_{\rm lo},s_{\rm hi}]-T_k)\cap[0,\Delta]$; if $\Sigma_k$ is empty the slab is not touched; otherwise the three polynomial expressions evaluated in interval arithmetic with $\sigma=\Sigma_k$ enclose $q$, $\dot q$, $\ddot q$ at every requested time that falls in slab $k$, because interval evaluation encloses the pointwise sets. Enlarging $\Sigma_k$ (for printed-string padding, or to $[0,\Delta+(\overline t_k-\underline t_k)]$ as a blunt allowance for the origin uncertainty) only enlarges the result and stays valid, provided the polynomial is never credited beyond what (iii) covers: values of $\sigma$ above $\Delta$ are not needed for the true slab and add only harmless width. **Uncertain origin.** Because $\tau_k$ is one unknown number in $T_k$, the difference $s-\tau_k$ must be taken with $T_k$ as an interval (not a point, not a midpoint); slabs $k$ and $k+1$ are both touched when the request straddles the possible join times $[\underline t_{k+1},\overline t_{k+1}]$. **Joins.** The enclosure of a request is the hull over every touched slab; at a join both neighbours are touched and both enclose the join state (the end of slab $k$ at $\sigma=\Delta$ and the start of slab $k+1$ at $\sigma=0$ are the same true state), so the hull is continuous across joins, including joins between record families, whose continuity is the exact-string chain control. **Original-window seam.** For requests reaching below $T^*$ the window part $[s_{\rm lo},T^*]$ is enclosed by the window enclosure (never by a slab polynomial, and never the window law above $T^*$), and hulled with the slab part. **Intersection with the whole-step box.** For one slab, the polynomial box and the whole-step box $(S,V_S,$ law-on-boxes acceleration$)$ are two proved enclosures of the same true values at the same requested times, so their intersection is a valid enclosure; the intersection must be formed slab by slab (or of the two complete hulls), never between a polynomial box of one slab and a whole-step box of another, and never when either inclusion is unproved (uncertified record, a record whose `a0`/`ap` fields are absent or not the consumed objects). **Refusals.** Uncertified records, a gap between consecutive coverage hulls, a request beyond the last certified slab, a record without the needed fields: refuse. **Implication for the delayed boxes.** A whole-step hull has coordinate width about $v'\Delta$ per touched slab ($0.002$ to $0.003$) and covers two or three slabs for a receiver-step request;
