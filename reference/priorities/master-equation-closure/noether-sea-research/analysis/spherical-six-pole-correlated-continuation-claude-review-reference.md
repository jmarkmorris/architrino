## 1. Inclusion theorem for a correlation-preserving step (derived)

**1.1 What is uncertain.** The true motion is ONE curve: the release is exact and the law deterministic. Enclosure widths are (i) interval overestimation and (ii) one genuine unknown, the true time offset of the window end $T^*$, which is a single number common to every record origin and every read. Consequently the only parameters a correlated representation may share without further proof are: $u_t\in[-1,1]$, the common origin offset (true $t_s=\hat t_s+\delta u_t$ for every step simultaneously, $\delta$ half the origin width); $u\in[-1,1]^2$, the position of the true state inside an ACCEPTED anchor box (a rectangular box licenses independent variation of its coordinates, so $q$ and $w$ get separate parameters); and, for every history record that is read but NOT reconstructed, its own independent box position. Tying $q$ and $w$, or a receiver state and an unreconstructed history read, to one common parameter without a proof is forbidden.

**1.2 Representation and its meaning.** $Z=\{\hat z+Cu+r:\ u\in U,\ r\in R\}$, $U=[-1,1]^m$, $C$ a point or interval matrix, $R$ a box. Meaning: with $u^\star$ the TRUE value of the latent parameters, the true $z$ lies in $\hat z+Cu^\star+R$. It does NOT claim that every $u\in U$ yields a true trajectory, and conversion to the box hull of $Z$ is always valid (and loses the correlation).

**1.3 The step theorem (mean-value/Lohner form).** Let $\Phi$ map the step's start state $z_0$, the common origin $u_t$, and the true delayed history to the end state $z_1$. Hypotheses: (H1) $Z_0$ contains the true $z_0$; (H2) $\Phi$ is Lipschitz in $(z_0,u_t)$ on the convex hull $K$ of the admissible inputs, with partial derivatives existing almost everywhere and enclosed by an interval matrix $[J]$ over $K$ and over every admissible history; at a seam where a delayed acceleration jumps, both one-sided values must lie in $[J]$; (H3) $[\Phi(\hat z_0)]$ encloses the image of the centre for every admissible history and origin; (H4) the delay roots are unique (sub-wake history, $D_c\ge1-|w'|>0$) and every read lies in guaranteed coverage. Conclusion: the true $z_1\in m([\Phi(\hat z_0)])+m([J])\,C_0u^\star+R_1$ with $R_1=([\Phi(\hat z_0)]-m)+([J]-m([J]))C_0U+[J]R_0+\rho$, $\rho$ the rounding of the products. Proof: the integral mean-value form $\Phi(z_0)-\Phi(\hat z_0)=\int_0^1J(\hat z_0+\theta(z_0-\hat z_0))\,d\theta\,(z_0-\hat z_0)$ holds for a Lipschitz map on a convex set with $J$ defined almost everywhere; $J\in[J]$ there, and $z_0-\hat z_0=C_0u^\star+r_0$. Re-orthogonalising $C_1$ (QR) is allowed if the remainder is transformed with an enclosure of the inverse.

**1.4 Uncertain origin.** $u_t$ is one true number, so carrying it as a SHARED column of every step and every history read is valid and exact. The law is autonomous; $\Phi$ depends on $u_t$ only through the history reads, so its column is $\partial\Phi/\partial H\cdot\dot H\,\partial s/\partial t_s$. Treating it instead as an independent box per step is valid but loses that cancellation.

**1.5 Delayed reads of the same history.** A class reads $H(s_c)$ with $s_c=t-\tau_c$ and $\tau_c=\rho_c(q(t),q(s_c))$. If the history at those source times is RECONSTRUCTED in the same parametrization, $H(s;u,u_t)$ must be given as a function enclosure valid for every $s$ in the read range (for example the record's own Taylor form in the step offset $\sigma$ with uncertain origin, its coefficients themselves correlated forms), and the read's sensitivity is $\partial H/\partial u+\dot H\,\partial s/\partial u$ with $\partial\tau/\partial u$ from implicit differentiation of the root equation (denominator $D_c>0$). If the history comes from unreconstructed frozen records, it is an INDEPENDENT box: it enters only $[\Phi(\hat z_0)]$, and its full width effect, about $|\partial\Phi/\partial H|$ times its width, is added at every step with no cancellation. That is the lost correlation, and it bounds what any receiver-only correlation can gain: the unlike class reads about $1.0$ to $1.3$ back, the like about $1.5$ to $1.75$, the antipode about $1.9$, so for steps after 5.57 the read history lies in steps about 255 to 330 whose own boxes are $0.005$ to $0.01$ wide.

**1.6 Taylor-model alternative.** Same obligations: validated TM arithmetic with Lagrange remainders for every elementary function over the full parameter domain, a Picard fixed point in TM form proved by strict inclusion, the history as TM in $(u,u_t,\sigma)$ or as independent boxes with the same loss.

**1.7 Intersection with a frozen accepted record (when valid).** If a frozen accepted record proves the true $z(t_k)\in B_k$ and the correlated set proves $z(t_k)\in Z_k$ for the SAME true instant (same origin convention), then $z(t_k)\in Z_k\cap B_k$: valid. Contracting the latent domain to $U'=\{u:(\hat z+Cu+R)\cap B_k\ne\emptyset\}$ (an outer enclosure of it) is also valid, because the true $u^\star$ satisfies it. INVALID: intersecting with a record of another instant, with an uncertified, provisional or possible-end record, with a set computed under unproved premises, or choosing a sub-box or midpoint because it fits. An EMPTY intersection is a contradiction and a defect, never a repair.

**1.8 Rounding and remainder obligations.** Outward interval arithmetic for the centre image, the Jacobian enclosure, the products $m([J])C$ (excess moved into $R$), the QR step and any inverse; every stored-rate premise of a record used as history kept (fourth-review wording); printed strings padded outward.

**1.9 What a reconstruction from an earlier accepted anchor must prove.** (a) The anchor is an accepted record whose box contains the true state at its true instant. (b) Every reconstructed step satisfies H1 to H4, with its history reads either reconstructed in the same parametrization or taken from accepted records as independent boxes, stated per class and step. (c) Coverage: every read below the guaranteed lower end of the reconstructed or accepted chain; roots unique. (d) Seams: none expected after source time 2.7; any other proved one-sided. (e) A necessary CONSISTENCY check at every reconstructed step end: the reconstructed set meets the frozen record box; a disjoint pair is a defect. (f) What is recertified: the reconstruction is a NEW certificate of the same history; old records stay frozen and true; later steps may consume the reconstructed history only after it is admitted like any slab. Falsifier of the theorem's use: a true state outside $Z_1$ under the stated hypotheses.
