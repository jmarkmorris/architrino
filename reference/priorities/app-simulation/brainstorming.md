# Simulation Concept Synthesis

This document synthesizes provisional simulation questions that are not accepted tasks or validation standards. Detailed executable protocols and campaign objects belong in [simulations.md](analysis/simulations.md); accepted work belongs in [work-queue.md](work-queue.md).

## Diagnostic Claim Boundary

A simulation diagnostic can nominate a branch chart, rerun, or comparison, but it does not establish retention, recovery, or ontology by itself. Threshold sensitivity, provenance value, wake-pattern return, and coarse-graining comparisons must be evaluated on the same declared histories as the causal-root, convergence, residual, and provenance records they supplement.

## Strong-Field and Scale Comparisons

Event-horizon alignment, inner-binary maximal-curvature behavior, and conventional Planck units occupy different claim layers. The first two are candidate branch mechanisms in the current theory program; Planck units are an observer-level comparison. A useful simulation must state the map among them rather than assuming that field-speed alignment is already a Planck-scale derivation.

## Native Finite-Assembly Comparisons

A nucleon-scale Monte Carlo target begins from a declared architrino inventory, regularized state history, causal-root ledger, Noether sea embedding, color-corridor account, observer-level hadronic comparison observables, and negative controls. Agreement with lattice-QCD or experiment would be comparison evidence about the retained native branch, not permission to import a lattice gauge configuration as substrate input.

Plainly: the simulation should build the candidate nucleon from the theory's own pieces and only then compare its outputs with established hadron calculations and measurements.
