### PHO-009 — Conditional formation-geometry relaxation

- **Status:** Deferred / blocked
- **Priority object:** `formation_geometry_relaxation`
- **Claim grade:** Guessed conditional hypothesis; no photon-geometry response has been derived or measured.
- **Conditional question / acceptance:** After an independently certified retained free-photon branch exists, determine whether explicit admissible source-coupled and ambient Noether sea states select distinct stable retained-branch geometries. Declare the compared geometry observables, including pair spacing, braid scale or shape ratios, and relative phase offsets, and distinguish a source-coupled release state from an asymptotic freely propagating state rather than calling the formation transient an equilibrium.
- **Relation to existing canon:** Photon Gate A treats pair spacing, phase frequency, geometric phase, and photon-channel speed as open branch variables, so it permits this question. It does not establish that geometry depends on local Noether sea state, and the separate target $c_\gamma=c_{\mathrm{eff}}$ does not entail that dependence.
- **Evidence / blockers:** No retained photon branch has been exhibited; no explicit source-coupled and ambient path-history configurations or accepted constitutive bridge from Noether sea state to EOM inputs has been declared; and no independent reference currently exists for the proposed geometry response. The Photon app may later consume or visualize accepted evidence, but it cannot establish the branch through prescribed geometry.
- **Barred adjacent claims:** Do not infer a photon-frequency shift, energy transfer, gravitational-redshift law, endpoint-only map, or path independence from a geometry response. Absolute time requires an explicit energy ledger; it does not exclude a path-history Noether sea sink, which remains an open closure target under its own observational constraints.
- **Falsifiers:** A converged, independently checked null response across the declared admissible environment family closes the proposed response only over that tested domain. Hysteresis, branch switching, nonzero closed-loop holonomy, or dependence on the transition rate falsifies an endpoint-only geometry map but does not by itself falsify every environmental response. Failure to produce a retained photon branch leaves the question without a referent rather than closing it negatively.
- **Completion:** Begin only after the retained photon branch and explicit environment inputs are certified. Complete with a controlled parameterized family, declared relaxation and stability criteria, forward-and-reverse environment paths, numerical-refinement evidence, and an independent oracle or theorem. The accepted result must either establish a nontrivial environment-to-geometry map or bound a null response over a declared domain; one run pair is insufficient.
