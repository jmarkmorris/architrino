# Dialogues

This priority area stages conversation-driven theory material before any corpus promotion.

Use it for AI-imagined reconstructions, real discussions, interview notes, and pasted exchanges that may sharpen $\mathbb{A}\mathbb{A}\mathbb{A}$ explanations, objections, analogies, proof routes, or candidate captures.

Each dialogue file should be named for the primary interlocutor when there is one clear interlocutor, for example `william-thurston.md`. Multi-person conversations can use a short topic or event slug when naming by a single person would misrepresent the exchange.

## Intake Rules

- State the source status near the top: real conversation, AI-imagined reconstruction, edited notes, or mixed source.
- For AI-imagined reconstructions, state that the text is not a historical quotation or attribution.
- Do not use AI-imagined reconstructions as evidence about a historical person's actual views.
- Preserve pasted material in a clearly marked conversation section.
- Rephrase operator prompts into succinct, theory-aware prose while preserving technical meaning.
- Separate useful theory pressure from corpus-ready claims.
- Promote only the distilled result into `content/markdown/aaa` when it becomes reader-facing and defensible.
