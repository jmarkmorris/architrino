# Geometric Phase and Holonomy

## Purpose and Ownership

This is a conceptual exploration within [Standard Model Mapping](../priorities.md), selected by the operator as a continuation of the enjoyable gauge-theory and ontology discussions. It asks how changes of mathematical convention differ from effects that survive a complete comparison. [SMC-012 in the parent work queue](../work-queue.md#smc-012--geometric-phase-and-holonomy-exploration) owns the first attention item; this directory creates no new scientific workstream or recovery gate.

**Claim level:** established geometric mathematics and observer-level comparison. A proposed connection to assembly or wake history is a recovery target, not an adopted substrate mechanism.

## The Central Question

How can a system return to the same visible configuration while a relative phase or orientation records the route taken?

Holonomy is the residual transformation obtained by transporting an object around a closed loop under a specified transport rule. A geometric phase is a phase contribution associated with the geometry of a parameter cycle. In the standard quantum adiabatic setting, Berry phase has a precise holonomy interpretation; this is comparison mathematics, not a premise about architrinos.

Plainly: returning to the starting point does not necessarily undo everything accumulated along the journey. The first job is to specify what is transported, how it is compared, and which part of the result survives a change of descriptive convention.

## Learning Path

1. **Convention versus comparison.** Give a small example of changing the phase convention without changing a physical prediction.
2. **Closed transport.** Work through one geometric loop with a stated transport rule and show the remaining orientation or phase change.
3. **Berry phase and gauge description.** Separate phase caused by ordinary time evolution from the geometric contribution; test which closed-cycle quantity remains unchanged under a permitted change of phase convention.
4. **Aharonov-Bohm comparison.** Read the existing benchmark and identify the measured relative phase and the native records a recovery would need. Keep its specific physical setup distinct from the Berry parameter-cycle example.
5. **Connection to spinors.** Compare with [spinors, rotations, and history](../../mapping-quantum/spinors-rotations-and-history/brainstorming.md), without treating every geometric phase as a spinor sign change or every loop as the same physical process.

Plainly: learn to distinguish a changed label from a changed comparison, then use one small loop to make that distinction concrete. Similar mathematics does not establish identical physical mechanisms.
