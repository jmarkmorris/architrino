Promotion status: `priority-only`. Closure status: `closed-rejected:sampled-phase-offset-improvement-implies-retention`. ## 1. Narrow Overread

The rejected implication is

$$
\left(
\text{a sampled rigid phase-offset row reduces tangential RMS relative to the zero-offset row}
\right)
\Longrightarrow
\left(
\text{the row is a retained fixed-speed neutral swarm branch}
\right).
$$

The antecedent is only a sampled improvement statement. It says that, inside the rigid octahedral phase-offset grid with fixed gauge

$$
\phi_1=0,
\qquad
(\phi_2,\phi_3)\in\text{sampled grid},
$$

one sampled row has smaller RMS tangential residual than the zero-offset row. The consequent is much stronger: it would require a retained fixed-speed neutral swarm branch on the same ledger identity, including closed support, root, dynamics, action, Noether, event, stability, and convergence rows.

This packet rejects that implication only. It does not reject the usefulness of phase offsets as a diagnostic, search coordinate, or preconditioner for later branch searches.

## 3. Sampled Improvement Row

On the default sampled scan,

| Row | $\phi_2$ | $\phi_3$ | RMS tangential residual | Max absolute tangential residual | Retention |
| --- | ---: | ---: | ---: | ---: | --- |
| Zero-offset row | $0$ | $0$ | $1.100959070572$ | $2.061720157439$ | `not_retained` |
| Best sampled row | $0$ | $2.792526803191$ | $0.930838366084$ | $2.596731132168$ | `not_retained` |

Thus the sampled RMS improvement is

$$
1.100959070572-0.930838366084
=
0.170120704488.
$$

This proves only that the sampled rigid phase-offset grid can reduce the RMS tangential residual relative to the zero-offset row. It does not prove fixed-speed force closure, because the best sampled row still has

$$
\max_i|\widetilde{\mathcal{R}}_{\mathrm{tan},i}|
=
2.596731132168
\ne 0.
$$

The best sampled row is therefore a residual-improved row, not a retained branch.

## 4. Retention Failure

The retained fixed-speed neutral swarm predicate is not an optimization score. It requires every required row in the same ledger identity to pass. The sampled phase-offset row fails that standard for at least the following reasons:

| Required row | Status from the consumed artifact |
| --- | --- |
| Tangential fixed-speed force closure | open, because the best sampled max/tangential residual remains nonzero |
| Root row | open for retention, because the scan is sampled and does not provide a support-complete interval-certified root ledger |
| Support row | open, because no support-band or support-complete carrier certificate is supplied |
| Action row | open, because the artifact declares `solves_dynamics=false` and supplies no action-derived branch scale |
| Noether and event rows | open, because no source provenance, exchange, self-hit, root-fold, support-boundary, or endpoint event ledger is closed |
| Stability and convergence rows | open, because no root-ledger-preserving variational or convergence certificate is supplied |

The implication therefore fails by direct artifact inspection:

$$
\text{sampled RMS improvement}
\nRightarrow
\text{retained fixed-speed neutral swarm branch}.
$$

The closure status is

$$
\texttt{closed-rejected:sampled-phase-offset-improvement-implies-retention}.
$$

The branch status for the consumed sampled rows remains

$$
\texttt{not\_retained}.
$$

## 5. Boundary Of The Rejection

This packet makes no claim that all possible phase offsets are impossible. It rejects only the narrow inference from the consumed sampled improvement row to retained fixed-speed neutral swarm retention.

It also makes no claim against:

1. deformed support-band carriers;
2. bounded-speed routes;
3. polarity reassignment beyond the consumed artifact;
4. controlled self-hit rows;
5. fold-layer rows;
6. medium-response rows;
7. shell swarm routes;
8. nested shell swarm routes;
9. general neutral swarm routes outside this rigid sampled phase-offset artifact.

Any later branch in those classes must be evaluated by its own declared ledger identity and retained only if the required rows close.
