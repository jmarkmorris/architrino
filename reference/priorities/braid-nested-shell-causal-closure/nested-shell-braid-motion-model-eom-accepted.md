## Shell Identification

For a candidate branch $q$, let $\pi_q:\{1,\ldots,6\}\to\{I,M,O\}$ be the declared shell assignment. The shell sets are

$$
\mathcal{I}_{\ell}^{(q)}
=
\{i:\pi_q(i)=\ell\},
\qquad
\ell\in\{I,M,O\}.
$$

The exact-binary chart imposes $|\mathcal{I}_{\ell}^{(q)}|=2$ for every shell. A more general nested shell braid chart keeps only three ordered radial support bands:

$$
R_I+\Delta_I < R_M-\Delta_M,
\qquad
R_M+\Delta_M < R_O-\Delta_O,
$$

with all inequalities evaluated on the retained branch window. The labels mean radial order first:

- $I$: inner support band; candidate high-cadence, high-curvature, self-hit/history-supported role.
- $M$: middle support band; candidate $c_f$ hinge and separator-sensitive transfer role.
- $O$: outer support band; candidate low-cadence, sub-field-speed boundary and external-coupling role.

The role alignment $I\leftrightarrow H$, $M\leftrightarrow M$, $O\leftrightarrow L$ is a branch result. It should be measured by cadence, speed regime, support radius, root ledger, and exposure rather than imposed by notation.

## Shell-Resolved EOM Exchange

Given the accepted Master EOM, each receiver architrino still receives hits from individual source architrinos, not from a shell as a whole. The shell-resolved bookkeeping is only a grouping of the same root ledger:

$$
\mathbf{a}_i(t)
=
\sum_{\ell'\in\{I,M,O\}}
\mathbf{a}_{i\leftarrow \ell'}^{(q)}(t),
$$

where

$$
\mathbf{a}_{i\leftarrow \ell'}^{(q)}(t)
=
\sum_{j\in\mathcal{I}_{\ell'}^{(q)}}
\sum_{t_0\in\mathcal{C}_{ij}^{(q)}(t)}
\kappa\,\sigma_{ij}
\frac{|q_iq_j|}
{r_{ij}^2(t;t_0)|J_{ij}(t;t_0)|}
\hat{\mathbf r}_{ij}(t;t_0).
$$

For a receiving shell $\ell$, define the aggregate exchange diagnostic

$$
\mathbf{a}_{\ell\leftarrow \ell'}^{\mathrm{agg}}(t)
=
\sum_{i\in\mathcal{I}_{\ell}^{(q)}}w_i^{(q)}
\mathbf{a}_{i\leftarrow \ell'}^{(q)}(t),
\qquad
\sum_{i\in\mathcal{I}_{\ell}^{(q)}}w_i^{(q)}=1.
$$

The three important exchange classes are:

| Exchange class | Root source | Dynamics role |
| --- | --- | --- |
| Self-hit | $i=j$ on an admitted positive-delay or regularized branch | History support and outward feedback, primarily expected in the inner high-cadence role. |
| Partner-hit | $j\ne i$ inside the same shell binary or support band | Local shell closure, attraction/repulsion balance, and binary-scale rotation. |
| Inter-layer hit | $j$ in another shell band | Motion transfer, phase correction, separator events, outer-envelope shielding, and external response. |

The branch is stable only when these grouped accelerations close the same root ledger, not merely when their cycle average looks small.

## Phase And Constraint Exchange

For each shell, the closed-cycle phase ledger should include intrinsic winding plus root-induced phase corrections:

$$
\mathcal{P}_{\ell}^{(q)}(T)
=
\int_0^T \omega_{\ell}^{(q)}(t)\,dt
+
\Phi_{\ell,\mathrm{self}}^{(q)}(T)
+
\Phi_{\ell,\mathrm{partner}}^{(q)}(T)
+
\sum_{\ell'\ne\ell}\Phi_{\ell\ell',\mathrm{inter}}^{(q)}(T)
-
2\pi k_{\ell}.
$$

Stable phase closure means

$$
\mathcal{P}_{I}^{(q)}(T)
=
\mathcal{P}_{M}^{(q)}(T)
=
\mathcal{P}_{O}^{(q)}(T)
=0,
\qquad
k_{\ell}\in\mathbb{Z},
$$

on the same active causal-root ledger. This is stronger than matching three visual orbital periods because the $\Phi$ terms record self, partner, and inter-layer root history.

The local constraint-exchange object can use the existing retuning form. With

$$
\mathbf{y}_q
=
\left(
\ln\nu_I,\ln\nu_M,\ln\nu_O,\,
\ln R_I,\ln R_M,\ln R_O,\,
\ln\lambda,\ln\xi
\right)^T,
$$

the same-branch retuning condition is

$$
D\mathcal{C}_q[\Delta\mathbf{y}]
+
\Delta\mathcal{C}_{\mathcal{G}}
=0.
$$

Here $\mathcal{C}_q$ collects phase closure, causal-root, separator, inter-layer wake-exchange, support, and stability rows. If $\Delta\mathcal{C}_{\mathcal{G}}\ne0$, the event is a branch transition or separator crossing rather than smooth breathing on the same branch.

## Layer-Decoupling Stability Test

The legacy three-ring coupling intuition should be translated as a branch-retention test, not as literal mechanical topology. A retained nested shell braid must resist perturbations that try to release one shell band from the other two while preserving the same primitive architrino inventory and declared root chart.

Let $E_{\mathrm{dec}}^{(q)}$ be the decoupling subspace of perturbations to $\mathbf{y}_q$ and the inter-layer exchange entries $\mathcal{G}_{IM},\mathcal{G}_{IO},\mathcal{G}_{MO}$ that reduce at least one inter-layer coupling or support gap without changing $\pi_q$ or the active root-source identities. The constrained return map for the same branch chart is

$$
\mathcal{T}_{q,\mathrm{dec}}
:
\left(
\delta\mathbf{y},
\delta\mathcal{G}_{IM},
\delta\mathcal{G}_{IO},
\delta\mathcal{G}_{MO}
\right)
\mapsto
\left(
\delta\mathbf{y}',
\delta\mathcal{G}_{IM}',
\delta\mathcal{G}_{IO}',
\delta\mathcal{G}_{MO}'
\right),
$$

with the same phase, causal-root, separator, support, and event-ledger rows used above. The branch is stable against layer release only if the quotient non-neutral multiplier on this decoupling subspace has a positive gap,

$$
\Delta_{\mathrm{dec}}^{(q)}
=
1-\rho\left(
D\mathcal{T}_{q,\mathrm{dec}}
\big\vert_{E_{\mathrm{dec}}^{(q)}/G}
\right)
>0,
$$

while the ordered support inequalities remain positive on the retained window. If the perturbation escapes the support bands, changes root-source identities, or crosses a separator, the outcome is not same-branch breathing. It is a declared branch transition or decay channel.

This test sharpens the three-layer minimality question. A two-band subsystem may have an open release direction in $E_{\mathrm{dec}}^{(q)}$; a three-band retained branch must show that the combined $IM$, $IO$, and $MO$ exchange rows return every admissible release direction to the same branch or else classify the failure explicitly. The first simulation version should kick each single inter-layer exchange row and each pair of exchange rows, then check whether root ledger, phase closure, support bands, $\Delta_{\mathrm{dec}}^{(q)}$, and the event ledger close on one branch identity.

## What Is Rigid, What Breathes, What Rotates

| Behavior | Candidate mathematical carrier | Interpretation |
| --- | --- | --- |
| Rigid | Polarity inventory, architrino identity, shell assignment on the chart, active root source identities, emission-order classes, integer winding rows, positive Jacobian floor, and retained event ledger | These are ledger rigidities. They define sameness of branch identity; they are not fixed radii or fixed visual paths. |
| Breathes | $R_I,R_M,R_O$, support widths $\Delta_{\ell}$, $\nu_{\ell}$, $\omega_{\ell}$, envelope scale $\lambda$, axis ratio $\xi$, and inter-layer exchange entries $\mathcal{G}_{IM},\mathcal{G}_{IO},\mathcal{G}_{MO}$ | Breathing is radial/cadence retuning required to keep phase and root closure after a transaction, translation, external gradient, or Noether sea change. |
| Rotates | Layer phases $\theta_{\ell}$, winding counts $k_{\ell}$, binary partner phases, support-plane or axis frames $\mathbf{A}_{\ell}$, and global orientation modulo gauge | Rotation is the ongoing branch motion and possible precession of the support bands. A stable branch rotates while preserving its ledger identity. |

Thus the stable assembly behaves like a nested shell braid because its invariant object is a path-history ledger, while its geometric carrier is allowed to retune. The phrase "stable shell" should mean "ledger-stable support band," not "unchanging spherical shell."

## First Simulation Question

The first discriminating experiment is not "can three drawn rings look stable?" It is:

> Starting from a six-architrino EOM integration with no imposed fixed radii, does the retained support descriptor converge to three ordered radial bands whose root ledger, phase closure, and Floquet gap persist under perturbation?

The failure modes are equally informative:

- one-band shell persistence with no ordered sub-bands: shell braid but not nested shell braid;
- ordered bands without positive stability gap: transient nesting only;
- positive whole-branch stability but $\Delta_{\mathrm{dec}}^{(q)}\le0$: nested support exists but is release-unstable under layer-decoupling perturbations;
- phase closure on one ledger but event or exchange closure on another: branch split;
- approximate $1:2:4$ cadence without branch-derived amplitudes or stability: numerology, not selection;
- successful support and phase closure but failed event ledger: dynamics branch exists, causal-closure export fails.
