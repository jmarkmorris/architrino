# Configuration Display Catalog

This catalog routes exact prescribed configurations into Borg without creating parent templates or preserving development aliases. Every leaf has one opaque `assemblyId`, one exact `modelRevisionSha256`, one factual label, and one reproducible `assembly-view-record.v0` display record. Borg performs no geometry construction, acceleration calculation, or scientific classification beyond deterministic descriptors of source-declared facts.

## Rendering and Verification

The [trail policy](../../../src/apps/borg/BorgOrbitTrails.mjs) retains red positrino and blue electrino markers and paths. A sole antipodal neutral pair on one circle receives two fading half-turn tails. Three or more occupants with equal signed angular rates receive preceding phase-gap arcs. Single-occupant circles receive solid full-turn trails. Missing or ambiguous carriers remain unavailable.

[Independent geometry checks](../../../tests/borg-configuration-geometry-records.test.js) use regular-polygon chord lengths, planar rotation, the co-spherical radius identity, Platonic edge counts and vertex degrees, and preservation of pair distances. Renderer tests check line spans, clipping, and exact polarity colors for every current catalog entry. Generator byte checks establish reproducibility only; none of these checks independently evaluates delayed acceleration or proves retention or stability.

Falsifier: an incorrect member or polarity count, an identity mismatch, a failed independent geometry invariant, a wrong circulation relation, a missing catalog entry, an obsolete record remaining addressable, or generator drift invalidates the corresponding display claim.
