## 1. Never idealize the delays

**The lesson.** Across the whole legacy arc, wrong answers traced to flattening the causal structure — treating delays as pointwise, uniform, or static — and corrections came from honoring exact per-pair delays. Causal delay is not a correction term in this theory; it is the theory.
**Recommended disposition:** method.md addition (instrument-acceptance rule: no accepted instrument may idealize delays).
**Source:** `braid-archive/braid-ideal/brainstorming.md` (~L3049).

## 2. Pinned versus tuned: interrogate every special value

**The lesson.** Distinguish tuned knife-edges (measure-zero parameter settings with no restoring response) from dynamically pinned critical surfaces (setpoints of two-sided feedback). Universally identical observed-particle properties demand the latter; any claimed special value must come with a feedback mechanism or be treated as tuning. Cautionary companion: an earlier proposed speed-holding mechanism failed exactly this test when its two-sided condition was examined — any revival must re-derive the condition first.
**Recommended disposition:** method.md addition (claim-grading rider for "special value" claims).
**Source:** `braid-archive/braid-ideal/brainstorming.md` (~L3053–3061).

## 3. Symmetric test points can force nulls: probe at broken symmetry

**The lesson.** A transport or coupling channel can be exactly zero at a maximally symmetric configuration because symmetry forbids it, opening as soon as the configuration is tilted or drifting. Before booking a null coupling, derive the selection rule at the test point and re-probe at a representative broken-symmetry state.
**Recommended disposition:** method.md addition (Stage S screening rule).
**Source:** `braid-archive/braid-ideal/coupled-braid-sea-complex-fixed-point-instrument-spec.md`, broken-symmetry probe framing.

## 4. Prehistory modes are different experiments; the hold-window question

**The lesson.** An impulsively started seed drags a contradictory static past; a self-consistently moving prehistory interacts with a different wake field — declare which, and run both, since the distinction can flip outcomes. The sharp extension (never run): memory has a hard edge, so holding a state on a target trajectory longer than the memory window erases its approach entirely — preparation-uniqueness. The well-posed experiment is sub-window holds: map how much held time erases how much history, releasing and testing for collapse exactly when hold exceeds the window. Where an object cannot hold the trajectory itself, the holding environment must supply an order-one share of the interaction — such states are inherently environment-bound.
**Recommended disposition:** split — the declare-both rule extends method.md's delay discipline; the hold-window experiment is a campaign objective (a clean rung-1-adjacent methodology run).
**Source:** `braid-archive/braid-ideal/noether-braid-retained-branch-strategy-memo-2026-07-06.md`, seed-mode sections; `braid-archive/braid-ideal/brainstorming.md` (~L3197–3230).

## 5. Rotating-wave reduction: solve the ideal family as algebra, then perturb

**The lesson.** On a fixed-coordinate common-frequency co-rotating ansatz with uniform center translation, state-dependent delays become constant lags, collapsing the delay system into transcendental algebra with a generically discrete solution set — an enumerable spectrum indexed by winding/root data. Workflow: solve the ideal family semi-analytically first, then run stability as perturbation around each solved member. Replaces blind sweeps with spectrum-plus-perturbation. (The constant-lag reduction itself survives in corpus as mathematics; the workflow prescription is the mined content.)
**Recommended disposition:** method.md addition (Stage S design pattern).
**Source:** `braid-archive/braid-ideal/brainstorming.md` (~L2712, 2810).

## 6. Covering degree ≠ frequency doubling ≠ action doubling

**The lesson.** Delay-map topology (winding counts, doubly-wrapped domains) may constrain admissible resonance classes but never supplies energy or action weights — weights come from reduced dynamics, since action density is non-uniform across delay sheets and can degenerate near the null separatrix. The legacy program repeatedly tripped here.
**Recommended disposition:** method.md addition (guardrail under claim grades).
**Source:** `braid-archive/braid-doubling-frequency-lock/phenomenological-heuristics.md`, guardrail sections.

## 7. Spin claims and stability claims are separate burdens

**The lesson.** Whether an assembly is dynamically stable and whether it has spinor character are different questions consuming different evidence: a stable periodic object can have trivial rotational return, and a marginal eigenvalue is not half-integer spin. Merge the two programs only if a single history-functional invariant provably controls both on the same record.
**Recommended disposition:** method.md addition (claim-scoping rule for the assembly-mapping rung).
**Source:** `braid-archive/braid-angular-momentum-spin/intrinsic-drift-precession-spin-interleaving-scope-decision.md`, separation sections.

## 8. Mode-stability questions order behind fixed-point existence

**The lesson.** Asking whether a mode decays presupposes a stationary state exists; run existence first or the stability question is ill-posed. Probe mode fate with a single-mode perturbation at the established state, never from a confounded free release.
**Recommended disposition:** method.md addition (extends the acceptance-gate ordering).
**Source:** `braid-archive/braid-ideal/return-cycle-relaxation-sigma-attractor-theorem-target.md`, dependency sections.
