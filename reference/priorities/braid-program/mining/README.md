# Mining

Staging area for content mined from the legacy `braid-*` directories. Rules:

1. Only insights and ideas enter — never proofs, calculations, numbers, or verdicts. Grade on entry is always **idea (unproven lead)**.
2. Every item carries a source citation — **this directory is the single sanctioned exemption to the repo-wide rule that no live document references `braid-archive/`** (operator-ratified 2026-07-15). Citations here are plain inert strings (never markdown links), name the legacy path and file, and exist so a mined idea keeps its provenance and cannot be mistaken for a new one. Legacy run labels may appear here and only here, as citations.
3. An item leaves this directory only by becoming a campaign objective, a brainstorming entry, or a configuration-chart consideration — at which point it is restated fresh in program terminology and its legacy label is dropped.
4. Nothing in this directory is load-bearing. A campaign may be motivated by a mined lead; it may never cite one as support.

The first mining pass is complete. [The BP-005 disposition review](2026-09-01-disposition-review.md) assigns exactly one keep, route, defer, or reject outcome to each of its forty-seven curated leads without upgrading any source note above **idea (unproven lead)**.
