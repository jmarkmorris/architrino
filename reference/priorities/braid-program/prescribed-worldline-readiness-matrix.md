Status: Frozen executable inventory for the migration from `prescribed-braid-spec.v1` to the individual-architrino and individual-worldline prescribed assembly specification. All class-1 and class-5 sources are migrated; SD3, F5, F6c, and F6b have executable prescribed sources and generated records; and the Borg display-only approval package is complete. F5 remains an active exploratory creative geometry despite its approved prescribed display row. This matrix records executable readiness only. It does not establish EOM compatibility, retention, stability, or particle-facing claims.

## Disposition Classes

1. Existing executable JSON requiring geometry-preserving migration.
2. Exact geometry owner exists and a new executable JSON can be produced.
3. Parameterized geometry exists, but a representative instance requires operator selection.
4. Geometry is incomplete and remains non-executable.
5. Scoped-negative or deprecated geometry retained only for reproducibility.
6. Taxonomy parent for which no arbitrary representative is invented.

Plainly: every registry row receives an explicit outcome. A row becomes drawable only when the repository already supplies enough information to identify every architrino, its polarity, and its complete displayed history.

## Claim Boundary

The matrix is a measured repository inventory plus derived routing from the named geometry owners. It establishes which rows can be represented as exact prescribed histories. It does not establish binding, return, retention, stability, energy closure, particle identity, or physical realization. It is falsified if a named owner lacks the stated inventory or map, if an omitted executable source exists, or if migration parity reveals an undeclared path change.

Plainly: this document decides what can be encoded honestly today. It does not decide which geometry nature keeps.

Closure goal: preserve the independently checked prescribed-assembly surface and close F-series geometry debt one named field artifact at a time without changing any candidate's analytical or dynamical status.
