# Barnes-Hut Lane — Hierarchical Acceleration for Equal and Opposite Point Transceivers

`app-barnes-hut` is the operator-selected working identity for a research lane whose goal is a new hierarchical many-body algorithm in the spirit of Barnes-Hut, adapted and extended for populations of equal and opposite point transceivers interacting through delayed causal wakes. The lane began on 2026-10-10 by collecting factual background on the Barnes-Hut treecode and its rivals, then recording candidate innovations for the architrino case. The folder name is provisional; a product name, if the lane produces an application, remains an operator decision.

This folder contains no executable algorithm, solver change, or numerical result. The developed explanation is owned by `manuscript.md`.

- [Priorities](priorities.md) — purpose, current disposition, dependencies and ownership.
- [Manuscript](manuscript.md) — Barnes-Hut primer, rival methods, and the candidate algorithm for equal and opposite point transceivers.
- [Work queue](work-queue.md) — accepted executable objects, with none runnable yet.
- [Brainstorming](brainstorming.md) — provisional ideas not yet developed into the manuscript.
- [Work log](work-log.md) — authorization, source-gathering and validation records.

The [EOM solver](../app-solver/priorities.md) owns the production evolution engine, including the implemented [certified far-field contribution enclosure](../app-solver/contracts/far-field-contribution-enclosure.md) and the designed [million-path certified execution architecture](../app-solver/contracts/million-path-certified-execution-architecture.md). This lane proposes algorithms against those contracts; it does not introduce a second solver.
