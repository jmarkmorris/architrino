# Archive-Analysis Source Synthesis

This synthesis reserves space for provisional archive leads, repair candidates, and source-bound report language that do not yet have a selected mining task or focused packet.

## Routing Boundary

An archive lead becomes actionable only after it names the source artifact, provenance, claim level, likely owner, and disposition test. Active mining remains with the parent [Source Mining](../priorities.md) tracker, while completed source identities and dispositions belong in its durable history.
