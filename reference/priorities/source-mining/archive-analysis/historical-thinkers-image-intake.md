## Notes

- Registry entries in `content/assets/images/images.json` are the provenance records: each imported image stores its source page, local file path, dimensions, SHA-256 hash, license label, creator/credit line, import date, and Wikidata id where available.
- This pass prioritized defensible reusable sources over exhaustive reverse-image searching. Names without a Wikidata P18 image, with missing Commons metadata, or with unclear licensing are listed above for a later manual pass if needed.
- Ancient thinkers are represented by canonical busts, engravings, or later art when no life portrait exists; the registry descriptions call these representative historical images rather than literal photographs.
