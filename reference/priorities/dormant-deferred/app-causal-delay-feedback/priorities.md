Keep the proposed advanced linked-view lesson deferred until an operator-directed teaching pass can simplify that burden within the existing app.

Reopen implementation only for:

- an operator-directed learner-surface change;
- a reproducible regression against the accepted requirements;
- an accessibility or browser defect that affects the live surface; or
- a deliberate change to recorded-dataset provenance or display authority.

There is no scheduled solver implementation in this app. The optional EOM path is a viewer for supplied recorded EOM datasets, not an active EOM solver animation or recomputation path.

Plainly: maintenance means protecting the accepted teaching app, not continuing the former solver-development backlog.
