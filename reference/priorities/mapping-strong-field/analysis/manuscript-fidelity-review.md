## Actionable clarification

### SF-F1: specify global orbit multiplicity and the block-stabilizer quantifier

At the initial manuscript's section 4.2, the sentence that global counting retains distinct extensions can be read as counting every distinct raw global label. The source's displayed definition instead counts the admitted raw fiber modulo the harmless group. Two raw labels related by harmless relabeling outside a block can induce the same local restriction and still form only one global orbit. Distinct global extensions contribute distinct global states only when they remain inequivalent under the global harmless action. Physically different histories and release routes must still remain distinct because the admissible action is forbidden to erase them.

The same paragraph introduces the block stabilizer but then says that “every global action” must descend. The source quantifies precisely over actions in the setwise stabilizer of that block. An action moving the block elsewhere is not an additional local descent obligation on this fixed block.

**Requested repair:** say explicitly that global counting retains inequivalent global extensions, meaning different global harmless-group orbits, and quantify descent over members of the block stabilizer. Record in coverage that this clarifies inherited source prose against its displayed global and local quotient definitions; leave the original source unchanged. A final reading of the corrected paragraph and coverage disposition will close this item. This is a mathematical wording clarification, not a new physical entropy result or a request to construct an ensemble.
