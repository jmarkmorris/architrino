## Current Terminology

The active reader-facing braid terms are:

| Term | Working meaning |
| --- | --- |
| `Noether braid` | The overall class of Noether-constrained braid models. Use Noether Braid in titles, headings, scene titles, and other title-case labels. |
| `neutral braid` | The broad six-architrino neutral case before any required binary grouping or radial organization is assumed. |
| `shell braid` | A neutral braid whose six architrino paths remain in a controlled radial support band. |
| `nested shell braid` | A shell braid with three ordered radial support bands. |

Formula notation currently uses $\rho_{\text{NS}}$ for physical Noether braid density and $\Lambda_{\text{NS}}$ for the reduced nested shell braid closure label. The temporary density spelling from the previous pass is retired. Other formula symbols with `core` subscripts, including $R_{\text{core}}$, $\omega_{\text{core}}$, $Q_{\mathrm{core}}$, and $\mathcal{F}_{\text{core}}$, remain compatibility symbols unless a separate approved row renames them.

The completed terminology migration table is archived in [Braid Migration Archive](braid-migration-archive.md).
