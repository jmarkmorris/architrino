## No-Go Applicability Map

Each no-go theorem should be converted into a four-part record:

| Field | Meaning |
| --- | --- |
| Assumptions used by the theorem | The exact locality, Hilbert-space, Lorentz, Markov, metric, statistical-independence, or regularity assumptions required. |
| $\mathbb{A}\mathbb{A}\mathbb{A}$ stance | Whether the assumption is accepted, rejected, replaced, or only effective. |
| Replacement burden | The theorem's constraint translated into an $\mathbb{A}\mathbb{A}\mathbb{A}$ condition that must still be satisfied. |
| Failure condition | What observed or derived result would reject the local $\mathbb{A}\mathbb{A}\mathbb{A}$ route. |

- a sector acceptance set with variables and pass/fail criteria;
