## 2. Converted Mathematical Signals

**Source signal.** If each architrino is constrained to internal carrier speed $c_f$, the acceleration supplied by causal-wake hits must not add tangential power along the carrier velocity.

**Converted object.** The necessary residual is

$$
\mathcal{R}_{\mathrm{tan},i}(t)
=
\mathbf{u}_i(t)\cdot
\left[
\sum_{(j,s)\in\mathcal{A}_i(t)}
\mathbf{F}_{ij}(t,s)
-
\ddot{\mathbf{C}}(t)
\right],
\qquad
\mathbf{u}_i=\dot{\mathbf{x}}_i-\dot{\mathbf{C}}.
$$

**Outcome.** `converted`. This is a branch-promotion gate, not a visual plausibility test.

**Outcome.** `converted`.

### 2.3 Same-Level Noncollision Clearance

**Outcome.** `deferred-with-blocker`.
