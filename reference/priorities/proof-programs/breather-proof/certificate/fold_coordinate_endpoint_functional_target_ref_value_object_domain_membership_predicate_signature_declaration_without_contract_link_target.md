## Declaration Targets

For each endpoint functional `e`, a proof-grade declaration packet must prove
all three declarations below:

| Declaration field | Required proof role |
| --- | --- |
| `membership_predicate_signature_symbol_declared` | Proves `is_target_ref_value_object_e` is a legitimate endpoint-local predicate symbol for the target ref/value object-domain membership predicate. |
| `membership_predicate_signature_domain_sort_declared` | Proves `target_ref_value_object_argument_e` is a legitimate domain sort for the predicate argument. |
| `membership_predicate_signature_codomain_sort_declared` | Proves `truth_value_judgment` is a legitimate codomain sort for the membership judgment. |

These declarations are not supplied by merely writing the convention in a
target note. A later proof packet must show that the declarations are formed
from the preserved definition source data without importing
`witness_object_has_contract_link` and without accepting a primitive signature
or primitive declaration rule.

## Non-Routes

This target rejects the following shortcuts:

| Non-route | Reason it remains rejected |
| --- | --- |
| target-note convention as declaration | Naming `is_target_ref_value_object_e`, `target_ref_value_object_argument_e`, and `truth_value_judgment` states the target, but it is not proof evidence. |
| source-equation handle as declaration | Source-equation handles remain source syntax and cannot declare predicate symbols or sorts. |
| endpoint value-map certification as declaration | Certification attaches endpoint values; it does not declare a predicate symbol or sort. |
| payload match as declaration | Payload matching records agreement; it does not declare a symbol or sort. |
| no-link guard as declaration | A no-link guard excludes a premise; it is not a symbol or sort declaration. |
| primitive declaration acceptance | Accepting the declarations as primitive would be a theory decision, not this proof route. |

## Required Proof Stack

A declaration proof attempt can advance this target only by supplying:

1. A proof-grade declaration of `membership_predicate_signature_symbol_declared`
   for each endpoint functional.
2. A proof-grade declaration of
   `membership_predicate_signature_domain_sort_declared`.
3. A proof-grade declaration of
   `membership_predicate_signature_codomain_sort_declared`.
4. A no-primitive-declaration argument showing the declarations are not being
   accepted merely by target-note convention.
5. A no-contract-link argument showing the declaration route does not import
   `witness_object_has_contract_link` directly or through inherited source
   scope.
6. A source-data derivation showing how the declarations follow from preserved
   definition source data.

Only after those declaration obligations are met may a downstream packet
attempt the target-object argument sort, the five non-argument-sort exclusions,
the no-contract-link premise absence proof, the complete derivation, and the
proof-grade signature.
