### Backup strategy proposal — October 25, 2026

The operator is considering a script for Desktop, Documents and `vibe`, Time Machine, or both. Recommendation, provisional: use Time Machine on an appropriately sized APFS Encrypted destination as the primary local backup; add a scripted copy only for a distinct need such as a directly browsable project export or an independent second destination. No implementation or setup is requested by this discussion.

[Apple's current Time Machine guidance](https://support.apple.com/en-us/104984) documents automatic backups, changed-file copying after the first backup, retained hourly/daily/weekly versions, restoration of files or migration to another Mac, and resumption of the backup schedule when the disk reconnects. This covers more of the recovery problem than an ordinary copy of three selected directories. A basic mirror script would need separately designed version retention, error reporting, interruption handling, metadata preservation and recovery verification; a mirror alone can replace an older useful copy with an unwanted current version. A script remains useful where its output or destination serves a purpose Time Machine does not satisfy. Two backup forms on the same SSD are not independent protection from loss of that SSD.

The proposed scope includes Desktop, Documents, all required `vibe` sources and Git metadata, and `.local-data/` research evidence. Exclude installed `node_modules/` dependencies; retain the mixed `.tmp/` tree initially until disposable families are distinguished from cited research artifacts. Other user data such as application settings and agent records should be considered when choosing exclusions rather than limiting recovery to the three directories by accident. Git ignore rules do not define Time Machine policy. Measured using `tmutil isexcluded` against `/Users/markmorris/Desktop`, `/Users/markmorris/Documents`, `/Users/markmorris/vibe`, and the repository's `.local-data`, `.tmp` and `node_modules` paths: all six report `[Included]`. This observes those paths' exclusion status only; it establishes neither backup destination configuration nor successful backup or inclusion of every descendant.

[Apple's destination guidance](https://support.apple.com/en-gb/guide/mac-help/mh15139/mac) prefers APFS or APFS Encrypted and says Windows-formatted disks require reformatting, which removes their data. Preserve needed existing SSD contents before reusing it. Apple recommends a destination with at least twice the Mac's storage capacity; actual retained history also depends on selected data and change volume. The present drive's capacity has not been qualified for the proposed full scope and desired retention. Time Machine prunes old versions as space is needed, so it is not a permanent archive of evidence intentionally removed from its source. Retain source evidence under its existing preservation obligations, and verify an initial recovery of an ordinary document and a research artifact to a separate location before relying on the new backup. No exclusions, schedules, destinations or payloads were changed, and no backup or restore was initiated.
