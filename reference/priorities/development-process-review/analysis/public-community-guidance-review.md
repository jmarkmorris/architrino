## Retain without change

Retain the repository/site distinction, Discussions for exploratory questions, issues for concrete tracked work, PRs for proposed edits, professional critique, openness to correction, and the distinction between evidence and speculation. The optional long-session checkpoint-tag advice was subsequently retired by explicit operator direction; this does not prohibit established release/provenance tags. The current document does not prescribe squash merges or require agents to bypass publication authority. Do not import internal PAT configuration or branch naming into this reader-facing guidance.
