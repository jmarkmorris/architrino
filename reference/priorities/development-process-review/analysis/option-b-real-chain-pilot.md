The isolated-copy experiment preserved the review boundary for the real moving-single-root scalar-gradient chain. The maximum scalar-gradient residual was `2.1183055309847987e-12`, within the existing `2e-9` threshold. The original test reported one pass and zero failures. The scalar run uses normalized field speed one and the unchanged reference implementation; it establishes bounded implementation behavior on the declared regular chart, not a global scalar, singular continuation, action, conservation account, or EOM solver acceptance.

The new result-record check compares the canonical paragraph's three-significant-digit maximum with the executed maximum, allowing half a unit of its last displayed digit. Its positive and negative literal controls passed before the real source was read. This checks the accuracy of one reported number; it is neither a proof oracle nor a comparison of every historical field. The original historical receipt was not rewritten or reissued.

## Missed errors, limitations, and adoption boundary

The passing numerical test did not detect the disconnected-chart wording, the missing dependency, or the wrong displayed residual. B exposed the first two for review; an additional explicit result comparison caught the third. None of these outcomes licenses a claim that the graph understands the theorem. An edge omitted from both the manually specified baseline and candidate would produce no edge diff. The baseline itself therefore needs independent human review of its scientific relationships before adoption.

Every changed byte remains review-required, including the harmless comment. This is deliberate preservation of A's modeled review boundary; it is not a measured false scientific result. The benefit demonstrated here is more informative review, not automatic classification of all harmless versus harmful changes. Review-time reduction was not a goal or criterion.

The baseline is exploratory. No live GitHub approval, operator identity, branch rule, or trusted acceptance consumer was established. Existing equations, checks, historical evidence, publication procedures, and enforcement authority were not transferred. The pilot validates a bounded package shape and fixed selectors, not the complete proposed production schema, cross-scope obligations, safe processing of arbitrary untrusted records, general graph history, or concurrency control. A negative result in any fixed expected case, altered scientific-reference bytes, or acceptance granted through a metadata refresh would overturn the corresponding pilot claim.

**Recommended subsequent decision:** review the mapped assumption/dependency edges and decide whether to authorize a separately scoped adoption step with the existing operator/GitHub review boundary and receipt consumer. This completed experiment is evidence for that decision, not authority to take it. The [adoption design](option-b-gradual-adoption-design.md) and [approval/pilot review](option-b-approval-and-pilot-review.md) retain their proposal status.
