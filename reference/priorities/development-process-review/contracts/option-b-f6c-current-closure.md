# Option B F6c current operational closure

## Authority and boundary

The operator approved checker-first implementation and separate agent review on September 12 before continuation of B-REM-1. This contract extends the existing independent, nonexecuting [closure verifier](../../../../scripts/eom/verify-f6c-bounded-operation-closure.mjs). It does not accept scientific results or change the coordinator's resource limits. Historical version-one invocations retain their fixed coordinator selection and existing verification; current execution uses version two. Historical verification is not an alternate current launch route.

A current invocation is an externally selected record with exactly `schema`, `root`, `coordinator`, `node`, `plan`, `control`, and `sourceMap`. Each file binding has its canonical absolute `path`, SHA-256 digest and byte count. The schema is `braid-program/observed-bounded-invocation.v2`. The owner selects these expectations before launch; coordinator output cannot choose or replace them. `verifyClosure(input, {expectedInvocation})` requires the supplied invocation to equal that independently retained expectation. An observer must obtain the manifest digest from its caller and must not select it by hashing whatever happens to be on disk.

The coordinator path is `scripts/eom/f6c-bounded-operation.mjs`; its source map is `reference/priorities/development-process-review/contracts/option-b-f6c-bounded-operation-sources.jsonld`, with scope `f6c-bounded-operation-current-source`. The source map uses the existing [current-source schema](option-b-current-source-admission.md), serialized as two-space-indented JSON followed by one newline. The verifier independently checks that serialization, digest, graph paths, source roles, unique admission and reader, relationship endpoints/revisions and admission coverage. The serialization requirement makes duplicate JSON member names detectable without importing the coordinator's manifest reader. The map cannot bind itself.

The exact serial command is `NODE COORDINATOR --plan PLAN --plan-sha256 PLAN_SHA --self-sha256 COORDINATOR_SHA --source-map-sha256 MAP_SHA`. A synthetic control replaces only `--plan` with `--control-plan`, retaining the original 120-second contraction; ordinary work retains the 1,800-second maximum. Different flags, ordering, selected executables, plan identities or digests reject. Streamed execution retains its own acceptance owner; this serial closure contract does not silently certify streamed output.

All map-selected sources, the map itself, selected Node and selected plan must survive final same-identity source capture. The operation record must include every map-selected source and the map. Existing exact exit-zero, process-group closure, lock absence, source/output identity, stage admission, guard acknowledgment, resource observation, host-capacity and pending-versus-complete predicates remain mandatory. A conditional coordinator message cannot become acceptance before independently observed terminal closure. The resulting receipt has schema `braid-program/f6c-bounded-operation-external-closure.v2` and retains false mathematical, H3 and physical authority flags.
