# Retired Instrument Fixtures

These nine `*-fixture.mjs` modules are the embedded-data fixtures preserved from the frozen legacy-campaign instrument set (`scripts/braid-ideal/*` and `tests/braid-ideal-*.test.js`, ~85 instruments and ~79 tests) retired on 2026-07-16 under the 2026-07-15 braid fresh-start and the solver-retirement migration plan's preservation rule. They carry the measured configuration and result rows that back conclusions recorded elsewhere in `reference/priorities/braid-archive`; the instruments and tests that produced and consumed them were deleted from the live tree and remain recoverable in full from git history at any commit before the retirement. The retirement also covered, per recorded Decision A, `scripts/angular-momentum/tri-binary-offset-family-runner.mjs` with its two active tests (`tests/rank2-rank6-branch-source-join-report.test.js`, `tests/angular-continuous-interval-witness-producer-target.test.js`); the runner's measured diagnostic rows survive in the still-live audit fixtures `scripts/solver-audits/fixtures/branch-provider-current-candidates.json` and `scripts/nested-shell-braid/fixtures/torque-wake-same-row-diagnostic-priority-target.json`, whose `source_ref`/`source_report_ref` strings now name a git-history-only path. Files in this directory are historical artifacts: do not execute them as evidence instruments or wire new consumers to them.
