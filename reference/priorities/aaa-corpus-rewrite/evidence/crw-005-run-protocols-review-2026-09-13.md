## Independent mathematical checks and boundaries

For RP-01, let a promoted observable computed at step $h$ be $Y_h=Y^\ast+\delta+Ch^{p}g$, where $Y^\ast$ is the exact value, $\delta$ is an error shared by every run of the instrument (a wrong kernel, a root missed at every resolution, an unbounded truncated tail), and the last term is the discretization error. Every hypothesis of the lemma is a difference or ratio of two such runs, and $\delta$ cancels from each: $Y_{h/2}-Y_h=C(2^{-p}-1)h^{p}g$ independently of $\delta$. A Node witness returned the difference $-0.050$ with $\delta=0$ as the known case and the identical $-0.050$ with $\delta=0.7$. The negative control cannot detect $\delta$ either, because it perturbs the model deliberately and checks only that the gates then fail. Correctness therefore requires a reference outside the family of runs, which is what the repair states. This is the same argument the Convergence Tests receipt records for CT-01; it is a property of self-comparison, not of any run.

For RP-02, a binary indicator takes values in $\{0,1\}$, and every element of that set satisfies $\le1$, so the displayed rule $\max_a\mathcal D_{\mathrm{GW},a}\le1$ cannot reject a packet on a completeness ratio as originally declared. The Node witness returned true for the known passing vector $(0.2,0.5,0)$, true for $(0.2,0.5,1)$ with a missing item encoded as $1$, and false with the missing item encoded as $2$. For RP-03, the repaired recipe bounds the root-time error on an isolating interval by $(\varepsilon_F+\varepsilon_g)/\nu_t$, where $\varepsilon_F$ is the residual tolerance, $\varepsilon_g$ bounds interpolation and evaluation error of the stored history, and $\nu_t$ is the floor on $|\partial_{T_t}F|=|D_t|$. Refining $\Delta T$ alone changes neither $\varepsilon_g$ nor the history spacing that sets it, so the emission-time error of every root, self-hit roots included, has a floor $\varepsilon_g/\nu_t$ that step refinement cannot lower. Halving the history step and tightening $\varepsilon_F$ with the step removes that floor at the rate the interpolant allows; nothing in this bound is an integrator-stability statement, which is why the repair says necessary rather than sufficient.

For RP-07, $C^1$ position histories have continuous velocity, so $D_t=c_f-\hat{\mathbf r}_t\cdot\mathbf V_t(T_t)$ is a single number at every root. A Lipschitz history has bounded velocity defined almost everywhere with possible jumps; at a root that coincides with a jump the two one-sided velocities give two values of $D_t$ and hence two acceleration weights $c_f/|D_t|$, so the root is an event, not a simple root. The containment $C^1\subset W^{1,\infty}$ on a bounded interval makes the first class the stricter of the two named, consistent with the chapter's `or a stricter history class`.
