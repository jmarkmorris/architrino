## Independent mathematical checks and boundaries

For RCL-01 and RCL-09, each residual is a magnitude of a sum of energies divided by an energy, hence dimensionless; the segment sum in the horizon residual has nonnegative summands, so it vanishes only when every segment's bracket vanishes. The chapter's $\Delta E$ entries are declared final-minus-initial gains, so $h(\nu^+-\nu^-)+\sum\Delta E=0$ states that a photon loss is matched by counterparty gains. These are bookkeeping identities, not derivations of any exchange mechanism.

For RCL-03, a rate integrated over an interval measured on the same clock is dimensionless; if the interval is measured on a different clock the integrand acquires the map Jacobian $dt_{\mathrm{eff}}/dT$, which is exactly what the bare-$t$ form concealed. No value of $\tau_{\mathrm{th}}$ was computed.

For RCL-04, in the PDG vacuum formula the CP-odd term is $2\sum_{i<j}\operatorname{Im}[U_{\alpha i}U^*_{\beta i}U^*_{\alpha j}U_{\beta j}]\sin2X_{ij}$ with the sign reversed for antineutrinos; setting $\beta=\alpha$ makes each product $\lvert U_{\alpha i}\rvert^2\lvert U_{\alpha j}\rvert^2$, whose imaginary part is zero, so the survival-channel difference vanishes in vacuum. The matter potential $\pm\sqrt2G_Fn_e$ changes sign between neutrinos and antineutrinos, so their transition probabilities in matter differ even at zero CP phase. Both are closed-form facts about the quoted comparison formulas, not $\mathbb{A}\mathbb{A}\mathbb{A}$ results.

For RCL-05, entropy conservation in the standard comparison calculation gives $g_{*s}(Ta)^3$ constant; with photons plus relativistic electrons and positrons $g_{*s}=2+\tfrac78\cdot4=\tfrac{11}{2}$ before annihilation and $2$ after, so the comoving photon number, proportional to $(Ta)^3$, rises by $\tfrac{11}{2}/2=\tfrac{11}{4}$. The reference value $\eta_{10}\approx6$ is the post-annihilation value by the PDG definition. This fixes the epoch obligation; it does not evaluate any source-window ledger.

For RCL-07, from $\Delta\ln\nu=-\mathcal Y$ follows $\nu^+=\nu^-e^{-\mathcal Y}$ and $\Delta E_\gamma=h\nu^-(e^{-\mathcal Y}-1)$; at $\mathcal Y=\ln2$ this is $-h\nu^-/2$, and the counterparties must gain $h\nu^-/2$. The check uses no numerical wake speed; any instantiation would set $c_f=1$. It does not derive the kernel $\mathcal K_\nu$.
