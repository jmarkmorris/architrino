## Independent mathematical checks and boundaries

For SIM-01 and SIM-04, with $c_f=1$ and a transmitter at rest at $\mathbf X_t$, the wake surface emitted at $T_t$ is $\|\mathbf X-\mathbf X_t\|=T-T_t$, so a fixed sensor at distance $r_k$ is reached exactly when $T-T_t=r_k$, giving $T_r=T_t+r_k$ and the inversion $T_t=T_r-r_k$. Three sensors at $r_k=1,2,4$ therefore hear one emission at $T_t+1$, $T_t+2$, $T_t+4$, in radius order. For a moving transmitter and a fixed sensor, the root condition $g(T_r,T_t)=\|\mathbf X_s-\mathbf X_t(T_t)\|-c_f(T_r-T_t)$ has $\partial_{T_t}g=D_t$ and $\partial_{T_r}g=-c_f$, so $dT_r/dT_t=D_t/c_f$, which is positive whenever $\|\mathbf V_t\|<c_f$; emission order is then preserved at one sensor. The surface density $q/(4\pi r^2)$ is the prefactor of the canonical wake-surface distribution $\rho=\frac{q}{4\pi r^2}\delta(r-c_f\Delta)H(\Delta)$ in the mathematics style guide, and the mollifier $\delta_\eta$ of width $\eta$ in $r-c_f\Delta$ has width $\eta/c_f=\eta$ in reception time at fixed $r$. These are symbolic identities checked by hand; they establish the expected values of the specified tests, not that any implementation meets them.

For the zero-self-root control, the same-transmitter root condition for a stationary architrino reads $0=c_f(T_r-T_t)$, so the only candidate is $T_t=T_r$, which the canonical convention $H(0)=0$ excludes. An empty root set gives zero acceleration and hence constant velocity, matching the contract's VAL-01 inertial control. This is derived from canon conventions, not measured on any solver.

For SIM-02, the boundary is definitional: a prescribed history is an input path, not a solution of the acceleration law, so a residual computed on it tests bookkeeping arithmetic rather than conservation. No numerical instantiation was run. For SIM-05, the dependence of $W^{\mathrm{acc}}=c_f/|D_t|$ on $\mathbf V_t(T_t)$ through $D_t=c_f-\hat{\mathbf r}_t\cdot\mathbf V_t(T_t)$ is read directly from the canonical per-hit law; a scalar potential and gradient sample at a grid node carries neither $T_t$ nor $\mathbf V_t(T_t)$.

Boundaries. Nothing here certifies the EOM solver, the existence of an implemented tier-1 test, regulator or history-limit convergence, or any self-hit branch. The chapter still uses $\mathbb{U}_{\text{now}}$ potential and gradient summaries in the cache description at the effective bookkeeping grade the run protocols assign them.
