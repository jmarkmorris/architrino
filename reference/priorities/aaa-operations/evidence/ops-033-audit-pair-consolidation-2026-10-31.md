## Exact selection and format

The scope lists all fourteen complete paths, original byte/line counts and SHA-256 identities, with the two frozen preservation manifests that independently bind them. It selects these audit runs and each run's `.json.consistency.json` companion:

| Campaign | Audit10 run |
| --- | --- |
| Path continuation | `G1-P1`, `G2-P2`, `G3-P3` |
| Post-turn | `GP2-R1R2R3`, `GP3-R4R5R6`, `GP6-P4P5`, `GP7-P6` |

No trajectory, derivative-audit record, log, source code or written review is selected for replacement. Format `architrino/audit-pair-bundle.v1` is gzip-compressed UTF-8 JSON. Each pair retains base audit bytes in base64 and one companion edit: byte offset, removed-byte count and inserted bytes in base64. Restoration concatenates the unchanged prefix, insertion and unchanged suffix. Scientific JSON is not parsed and reserialized for reconstruction, so whitespace, spelling, key order and trailing-newline status survive. Permissions, timestamps and extended attributes are outside this byte-preservation scope.

The decoder checks the bundle size/hash, every decoded original size/line count/hash, allowed paths, edit bounds and unique member paths before creating a restoration destination. It limits decompressed input, uses exclusive file creation and refuses existing destinations. It has no deletion operation. Restoration needs the tool, bundle and manifest; it does not need original JSON or the scientific environment. Recompression across Node/zlib versions is not promised to retain gzip bytes; decoded original identities are the preservation criterion.

## Commands

From the checkout root, verify the candidate and compare every recovered byte with the current originals:

```bash
node scripts/retention/audit-pair-bundle.mjs verify --bundle .local-data/aaa-operations/ops-033/2026-10-31/audit-pair-consolidation-v1/audit-pairs.json.gz --manifest .local-data/aaa-operations/ops-033/2026-10-31/audit-pair-consolidation-v1/manifest.json --compare-root .
```

Restore both original generations with their repository-relative paths under a new directory:

```bash
node scripts/retention/audit-pair-bundle.mjs restore --bundle .local-data/aaa-operations/ops-033/2026-10-31/audit-pair-consolidation-v1/audit-pairs.json.gz --manifest .local-data/aaa-operations/ops-033/2026-10-31/audit-pair-consolidation-v1/manifest.json --out .tmp/ops-033-audit-pair-restored
```
