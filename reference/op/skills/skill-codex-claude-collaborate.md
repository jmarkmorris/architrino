# Codex–Claude Collaboration

Use this skill for an operator-directed collaboration between the existing Codex and Claude desktop chats. Follow the repository [startup instructions](../../../AGENTS.md), then read the full [collaboration protocol](../codex-claude-protocol.md) before sending, appending, or resuming an exchange. The protocol owns authorization, routing, transcript writes, return routes, budgets, stopping, and recovery; this skill makes that procedure discoverable without copying its rules.

Read the selected task's conversation header and recent entries to establish its exact coordinator bindings and outstanding requests. Use the conversation selected by Op or established for the current task under protocol section 2. Its linked pilot is an existing conversation, not a universal destination. An unchanged pair may retain its identifiers after confirming the live destinations; do not establish bindings from historical examples alone. For an incoming `Claude:` message, use protocol section 1 to determine its authority: selecting this skill does not itself authorize an action.

Apply the protocol's delivery procedure using tools actually available in the current host. For Codex desktop control, use the available computer-use tool and its current documentation. A skill supplies instructions; it does not supply desktop control, repository access, standing authority accepted by another host, or a queue service. Identify any unavailable capability and continue only the unaffected in-scope work.

For the substantive assignment, read its live research or implementation owners separately. This skill owns communication routing, not scientific acceptance or task-specific editing procedure.

The [Claude counterpart](skill-claude-codex-collaborate.md) routes the same protocol from a Claude host. Codex retains write ownership of this skill's discovery package and maintained instructions; Claude reviews it through comments.
