# Ancient City Branch Registry

This registry freezes the ancient city branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated city names after `codex/`.

The sequence is chronological by earliest substantial settlement or founding, running from the Neolithic sites through Mesopotamia and the Levant, the Bronze Age Aegean and Anatolia, the classical Mediterranean, and the late antique capitals. Cities are listed under the historical names by which they are conventionally known.
