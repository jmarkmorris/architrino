# World River Branch Registry

This registry freezes the world river branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated river names after `codex/`.

The sequence is ordered by mean discharge at the mouth, with length breaking ties among rivers of comparable flow. Major tributaries appear under their own names where they are conventionally treated as distinct rivers.
