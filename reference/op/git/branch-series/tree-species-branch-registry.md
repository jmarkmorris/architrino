# Tree Species Branch Registry

This registry freezes the tree branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated common names after `codex/`.

The sequence lists conifers and other gymnosperms first, then broadleaved trees, each grouped by family and running from temperate to tropical. Entries name the common group rather than a single species where the common name conventionally covers a genus.
