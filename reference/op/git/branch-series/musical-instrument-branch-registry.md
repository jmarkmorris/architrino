# Musical Instrument Branch Registry

This registry freezes the musical instrument branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated instrument names after `codex/`.

The sequence follows orchestral score order by family, from strings through woodwinds, brass, and percussion, then the keyboard instruments and the plucked instruments outside the standard orchestra. Within each family the ordering runs from higher to lower register.
