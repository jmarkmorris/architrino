# Mountain Peak Branch Registry

This registry freezes the mountain peak branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated peak names after `codex/`.

The sequence is ordered by elevation above sea level, descending, which groups the Himalaya and Karakorum first, then the Central Asian ranges, the Andes, the North American peaks, and the prominent African and European summits.
