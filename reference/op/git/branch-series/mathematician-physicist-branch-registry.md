# Mathematician and Physicist Branch Registry

This registry freezes the mathematician and physicist branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated surnames after `codex/`.

The sequence is chronological by birth, running from classical antiquity through the medieval Islamic and Indian traditions, the early modern analysts, the nineteenth-century algebraists and field theorists, and the founders of relativity, quantum mechanics, and computability. Surnames are transliterated to ASCII, so `codex/poincare`, `codex/schrodinger`, and `codex/godel` carry no diacritics.

Kepler, Galileo, and Fermi are absent because those tokens are consumed by the NASA space mission registry, and branch names are never reused.
