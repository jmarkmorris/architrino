# Exploration Ship Branch Registry

This registry freezes the exploration ship branch order required by [pr-lifecycle.md](../pr-lifecycle.md). Branch names use lowercase hyphenated vessel names after `codex/`.

The sequence is chronological by the voyage for which each vessel is best known, running from the age of sail through the polar expeditions to the modern oceanographic and ice-capable research fleet.
