# Children's Book Production Prompts

This folder holds book-specific image-generation briefs for the children's book production pipeline.

These prompts are production assets. They describe source illustrations for named books, covers, spreads, and backmatter activities, and they should stay with the generated image manifest, QA records, page layouts, and derivative exports under `reference/archie/childrens-books/production/`.

For reusable agent/operator workflow prompts, use the [CTO prompt library](../../../../research-office/cto/prompts/README.md).
