# Farther Takes Longer

Book: 7

Age interval: `6-7`

Series frame: **The Wonder of Nature and the Universe**

Wonder question: Why does farther take longer?

Discovery sentence: If a message travels at a speed, distance changes arrival time.

## Book Promise

This early elementary book teaches:

1. Farther messages arrive later.
2. Direction matters.
3. Starting place and arrival place define a line of action.

Parent/teacher terms: `distance`, `direction`, `field speed`, `source`, `arrival place`, `line of action`.

## Read-Aloud Manuscript

### Cover

Read-aloud title:

> Farther Takes Longer

### Spread 1: Two Bells

Read-aloud text:

> Electra set one bell nearby.
>
> Poz set one bell far away.
>
> "Which message arrives first?"

Editor note:

Distance becomes a testable question.

### Spread 2: Same Tap

Read-aloud text:

> Tap near.
>
> Tap far.
>
> Same tap.
>
> Different distance.

Editor note:

One variable is changed.

### Spread 3: Near First

Read-aloud text:

> The near bell answered first.
>
> Electra smiled.
>
> "Short path."

Editor note:

Shorter distance gives earlier arrival.

### Spread 4: Far Later

Read-aloud text:

> The far bell answered later.
>
> Poz counted the wait.

Editor note:

Longer distance gives later arrival.

### Spread 5: The Rope Wave

Read-aloud text:

> Poz flicked a rope.
>
> The wave ran along it.

Editor note:

A traveling shape can show finite speed.

### Spread 6: Not A Jump

Read-aloud text:

> The wave did not jump to the end.
>
> It crossed every place between.

Editor note:

Travel takes time through intervening places.

### Spread 7: Change Direction

Read-aloud text:

> Electra moved the bell left.
>
> The message path turned left too.

Editor note:

The arrival place sets direction.

### Spread 8: The Line

Read-aloud text:

> Poz drew from the start to the bell.
>
> "This is the line the answer follows."

Editor note:

A start-to-arrival line has a direction.

### Spread 9: Faster Or Slower

Read-aloud text:

> They tried a slow rolling ball.
>
> They tried a quick light flash.
>
> Speed mattered too.

Editor note:

Arrival depends on both distance and speed.

### Spread 10: The Same Rule

Read-aloud text:

> Clap.
>
> Ripple.
>
> Rope.
>
> Roll.
>
> Farther took longer.

Editor note:

Different systems can share one rule.

### Spread 11: Predict The Arrival

Read-aloud text:

> "Move it farther,"
>
> Electra said.
>
> "I predict a longer wait."

Editor note:

The rule supports prediction.

### Spread 12: The Discovery

Read-aloud text:

> A message has a path.
>
> A path has a length.
>
> Farther takes longer.

Editor note:

Distance, speed, and direction prepare field-speed intuition.

## Parent Note

This book is still grounded in ordinary play. The technical bridge is `field speed`: later potential waves do not act everywhere instantly; they arrive according to travel geometry.
